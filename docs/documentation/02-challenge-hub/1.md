# مركز التحدي — الهرمية الكاملة

## هرمية التنقل

```
مركز التحدي
  │
  ├── المادة (من مواد خطة الطالب)
  │    │
  │    ├── تراك ١
  │    │    │
  │    │    ├── وحدة ١
  │    │    │    ├── توبيك ١  ← آخر مستوى (لا يوجد دروس)
  │    │    │    ├── توبيك ٢
  │    │    │    └── توبيك ٣
  │    │    │
  │    │    └── وحدة ٢
  │    │         ├── توبيك ٤
  │    │         └── توبيك ٥
  │    │
  │    └── تراك ٢
  │         └── ...
  │
  └── مادة أخرى
       └── ...
```

ملاحظة: الهرمية مطابقة للمسار العادي (مادة ← تراك ← وحدة ← توبيك) بدون مستوى الدرس.
المصدر: نفس جداول الهرمية الموجودة بالسيستم حالياً.

---

## شروط فتح التوبيك

```
هل الطالب عنده صلاحية وصول؟ (اشتراك / شراء / محتوى مجاني)
  │
  ├── لا ← مقفل 🔒
  │         رسالة: "روح كمّل من المسار العادي"
  │         (هناك يكتشف إنه لازم يشتري)
  │
  └── نعم ← هل ختم كل دروس هذا التوبيك بالمسار العادي؟
               │
               ├── لا ← مقفل 🔒
               │         رسالة: "روح اختم الدرس أولاً"
               │
               └── نعم ← هل هذا أول توبيك بالوحدة؟
                          │
                          ├── نعم ← مفتوح 🔓
                          │
                          └── لا ← هل التوبيك السابق مختوم بمركز التحدي؟
                                     │
                                     ├── نعم ← مفتوح 🔓
                                     └── لا ← مقفل 🔒
                                               رسالة: "اختم التوبيك السابق أولاً"
```

نظام الصلاحيات: نفس النظام الموجود بالسيستم حالياً بالضبط
  (صلاحية على مستوى المادة / التراك / المحتوى المجاني / خطة مجانية)

## التوبيك الفاضي (بدون أسئلة ضع دائرة)

```
توبيك ما عنده ولا سؤال ضع دائرة من جدول
Review Item
  │
  ├── لا يظهر للطالب (مخفي بالكامل)
  │
  └── ينختم تلقائياً فقط إذا التوبيك اللي قبله مختوم
       (يرث حالة اللي قبله)

مثال:
  توبيك ١: مسكر
  توبيك ٢: فاضي ← اللي قبله مسكر ← يبقى مسكر
  توبيك ٣: اللي قبله (٢) مسكر ← يبقى مسكر

  توبيك ١: مختوم ✓
  توبيك ٢: فاضي ← اللي قبله مختوم ← ينختم تلقائياً ✓
  توبيك ٣: اللي قبله (٢) مختوم تلقائياً ← ينفتح 🔓
```

## مصدر الأسئلة

```
جدول
Review Item
  │
  ├── فلتر: التوبيك المحدد فقط
  ├── نوع: ضع دائرة فقط (كل الأسئلة بالجدول من هذا النوع أصلاً)
  ├── عدد: كل الأسئلة المتاحة بدون حد أقصى
  └── ترتيب: عشوائي كل مرة (حتى عند إعادة المحاولة)
```

---

## آلية اللعب

```
الطالب يفتح مركز التحدي
  │
  ├── يختار مادة (من مواد خطته)
  │    └── يشوف التراكات
  │         └── يختار تراك
  │              └── يشوف الوحدات
  │                   └── يختار وحدة
  │                        └── يشوف التوبيكات (مفتوح / مقفل / مختوم)
  │                             └── يختار توبيك مفتوح
  │                                  │
  │                                  ▼
  │                          ┌─────────────────────────────┐
  │                          │ كل الأسئلة المتاحة          │
  │                          │ بترتيب عشوائي               │
  │                          │ سؤال سؤال (بدون رجوع)       │
  │                          │ كل سؤال غلط → يظهر الجواب   │
  │                          │ الصح فوراً                   │
  │                          └─────────────────────────────┘
  │                                  │
  │                                  ▼
  │                          ┌─────────────────────────────┐
  │                          │ النتيجة:                     │
  │                          │ >= ٥٠٪  ← ناجح ✓ يُختم     │
  │                          │ < ٥٠٪   ← راسب ✗ يعيد      │
  │                          └─────────────────────────────┘
  │
  └── توبيك واحد فقط بالمرة الواحدة
```

---

## المحاولة غير المكتملة

```
الطالب طلع بنص المحاولة (أغلق التطبيق / رجع للخلف)
  │
  └── تُلغى بالكامل
       ├── لا تُحفظ
       ├── لا تروح للخوارزمية
       └── كأنها ما صارت
```

---

## إعادة المحاولة

```
مسموحة بعدد غير محدود — حتى بعد ختم التوبيك

السيناريو:
  محاولة ١ ← رسب (٤٠٪) ← تنحفظ + تروح للخوارزمية
  محاولة ٢ ← نجح (٧٠٪) ← تنحفظ + تروح للخوارزمية ← التوبيك يُختم
  محاولة ٣ ← رسب (٣٠٪) ← تنحفظ + تروح للخوارزمية ← التوبيك يبقى مختوم

┌─────────────────────────────────────────────────────────┐
│                                                          │
│  النسبة المحفوظة للعرض = أعلى نسبة ناجحة (٧٠٪)        │
│  لا ترجع لراسب أبداً بعد النجاح                         │
│                                                          │
│  الخوارزمية = كل محاولة تُرسل كاملة بغض النظر          │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## الوقت

```
لا يوجد حد زمني للمحاولة حالياً
الوقت يُسجل للتحليل فقط
ملاحظة: ممكن مستقبلاً نضيف حد للأرقام غير المنطقية (لاحقاً)
```

---

## تدفق البيانات

```
الفرونت إند
  │
  ├── يحسب النسبة ويقرر نجح أو رسب
  │   (لأن الأجوبة الصحيحة عنده أصلاً — يعرضها للطالب بعد كل سؤال)
  │
  └── يبعث طلب واحد للسيرفر يحتوي:
       ├── نتيجة المحاولة (نسبة، نجح/رسب)
       └── تفاصيل كل سؤال
            │
            ▼
       السيرفر يستلم ويتكفل بـ:
            ├── حفظ المحاولة بجدول التحليل
            └── إرسال نتائج الأسئلة للخوارزمية
                (نفس طريقة المسار العادي — التفاصيل للباك إند)

ملاحظة معمارية:
  الكتابة على الداتابيس ممكن تمر عبر
  background job
  أو نظام باتشز/كيو على مستوى السيستم كله (ليس خاص بمركز التحدي)
  التفاصيل تُترك للباك إند عند التنفيذ
```

## تقدم الطالب البصري

```
يُحسب من جهة الفرونت إند
لأن الفرونت إند يعرف أي توبيكات مختومة وأي لا

الوحدة = مجرد حاوية — لا تُخزن حالة ختم بالسيرفر
الفرونت إند يحسب إذا كل توبيكاتها مختومة

مثال:
  وحدة ١: ████░░░░ ٣/٥ توبيكات
  وحدة ٢: ░░░░░░░░ ٠/٤ توبيكات
```

---

## لا يؤثر على

```
  ✗ لا يؤثر على الإحصائيات العامة
  ✗ لا يؤثر على نقاط الخبرة الرئيسية للاعب (XP)
  ✗ لا يؤثر على المتصدرين الرئيسيين
  ✗ لا يؤثر على الستريك

  ✓ يؤثر على الخوارزمية (FSRS) — كل سؤال يُرسل
  ✓ يؤثر على نقاط خبرة مركز التحدي (منفصلة تماماً)
  ✓ يؤثر على ليدربورد مركز التحدي (منفصل تماماً)
```

---

## نقاط خبرة مركز التحدي

```
منفصلة تماماً عن نقاط الخبرة الرئيسية للاعب

كل سؤال صح = عدد ثابت من النقاط (مثلاً ٥ نقاط)
  ← عشان العدالة بين التوبيكات

مثال:
  توبيك فيه ٢٠ سؤال × ٥ نقاط = ١٠٠ نقطة كحد أقصى للتوبيك

آلية الحساب — مبنية على أعلى نسبة عموماً (ليس أعلى نسبة ناجحة):

  محاولة ١: ٤٠٪ رسب ← يكسب نقاط ٤٠٪ من الأسئلة (٨ أسئلة × ٥ = ٤٠ نقطة)
  محاولة ٢: ٣٠٪ رسب ← ما يكسب شيء (أقل من ٤٠٪)
  محاولة ٣: ٧٠٪ نجح ← يكسب الفرق ٣٠٪ فقط (٦ أسئلة × ٥ = ٣٠ نقطة)
  محاولة ٤: ٥٠٪ نجح ← ما يكسب شيء (أقل من ٧٠٪)
  محاولة ٥: ٩٠٪ نجح ← يكسب الفرق ٢٠٪ فقط (٤ أسئلة × ٥ = ٢٠ نقطة)

  المجموع التراكمي = ٤٠ + ٣٠ + ٢٠ = ٩٠ نقطة

┌─────────────────────────────────────────────────────────┐
│                                                          │
│  ملاحظة مهمة:                                           │
│  "أعلى نسبة عموماً" (لحساب النقاط) ≠ "أعلى نسبة ناجحة" │
│  (لحالة الختم والعرض)                                    │
│                                                          │
│  أعلى نسبة عموماً = أعلى نسبة سواء نجح أو رسب           │
│  أعلى نسبة ناجحة = أعلى نسبة >= ٥٠٪ فقط                │
│                                                          │
│  الهدف: تحفيز الطالب يرجع يعيد حتى بعد الختم            │
│  عشان يعلّي نقاطه ويتقدم بالليدربورد                     │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## ليدربورد مركز التحدي

```
منفصل تماماً عن الليدربورد الرئيسي

مستويان:
  ├── ليدربورد المادة: نقاط الطالب بمادة معينة
  └── ليدربورد الخطة: مجموع نقاط الطالب بكل المواد

التنافس: فقط بين طلاب نفس الخطة

العرض:
  ├── أعلى ٢٠ طالب
  └── ترتيب الطالب نفسه (حتى لو مش ضمن أعلى ٢٠)

التحديث:
  ├── ليس لحظياً — يتحدث كل فترة زمنية لتخفيف الحمل
  └── الفترة يقررها الباك إند عند التنفيذ

التصفير:
  └── يتصفر مع الموسم الجديد
```

## كاش أسئلة التوبيك (ملفات جيسون)

```
الهدف: تخفيف الحمل على الداتابيس

بدل ما نجيب أسئلة التوبيك من الداتابيس كل مرة:
  ├── نبني ملف جيسون لكل توبيك
  ├── الملف يحتوي على كل الأسئلة + معلومات التوبيك
  └── يُحفظ على
       CDN
       والفرونت إند يقرأه مباشرة

نفس فكرة كاش الهرمية الموجودة بالسيستم حالياً

ملف واحد لكل توبيك:
  ├── ١٠٠٠ توبيك = ١٠٠٠ ملف جيسون
  └── المرجع النهائي يبقى الداتابيس

إعادة البناء:
  ├── لما المعلم يعدل / يضيف / يحذف سؤال
  └── نفس آلية إعادة البناء الموجودة بالهرمية حالياً

محتوى الملف:
  ├── بيانات الأسئلة (نص، خيارات، جواب صح)
  ├── معلومات التوبيك (اسم، عدد الأسئلة، ...)
  └── ملاحظة: الباك إند يتحقق من الحقول الإضافية
       الممكن إضافتها بناءً على بنية البناء الحالية
```

---

## المواسم

```
عند انتهاء الموسم (وليس عند بدء موسم جديد):
  ├── بيانات الموسم تُؤرشف أولاً
  ├── ثم تقدم مركز التحدي يتصفر بالكامل
  ├── التوبيكات المختومة تُلغى
  ├── نقاط الخبرة تتصفر
  └── الليدربورد يتصفر

ملاحظة: تفاصيل الأرشفة لاحقاً (ليست ضمن النطاق الحالي)
```

## شاشات الأدمن

```
ليست ضمن النطاق الحالي — جلسة منفصلة
البيانات التحليلية جاهزة بجدول المحاولات
```

## ملخص القرارات

```
┌─────┬──────────────────────────────────────────────────────────┐
│  ١  │ الهرمية: مادة ← تراك ← وحدة ← توبيك (بدون درس)       │
│  ٢  │ نفس نظام الصلاحيات الموجود بالسيستم                    │
│  ٣  │ شروط الفتح: صلاحية + ختم بالمسار العادي + ختم السابق   │
│  ٤  │ توبيك فاضي: مخفي + يرث حالة اللي قبله                  │
│  ٥  │ الأسئلة من جدول ريفيو آيتم (ضع دائرة فقط)             │
│  ٦  │ كل الأسئلة المتاحة بترتيب عشوائي                       │
│  ٧  │ لا رجوع لسؤال سابق أثناء المحاولة                      │
│  ٨  │ نسبة نجاح ٥٠٪ لختم التوبيك                             │
│  ٩  │ محاولة غير مكتملة = تُلغى بالكامل                      │
│ ١٠  │ إعادة المحاولة مسموحة بلا حدود (حتى بعد الختم)         │
│ ١١  │ أعلى نسبة ناجحة تُحفظ ولا ترجع لراسب                   │
│ ١٢  │ كل سؤال يُرسل للخوارزمية (نفس طريقة المسار العادي)     │
│ ١٣  │ الفرونت إند يحسب النتيجة ويبعث طلب واحد                │
│ ١٤  │ كل محاولة تُحفظ للتحليل مع: وقت كل سؤال + الخيار      │
│ ١٥  │ التقدم البصري والوحدة يُحسبان من الفرونت إند            │
│ ١٦  │ لا تأثير على XP / متصدرين / ستريك / إحصائيات الرئيسية  │
│ ١٧  │ لا حد زمني حالياً (مع تسجيل الوقت للتحليل)             │
│ ١٨  │ يتصفر عند انتهاء الموسم (أرشفة لاحقاً)                   │
│ ١٩  │ شاشات الأدمن بجلسة منفصلة                              │
│ ٢٠  │ نقاط خبرة منفصلة: كل سؤال صح = نقاط ثابتة              │
│ ٢١  │ النقاط تُحسب على أعلى نسبة عموماً + الفرق التراكمي     │
│ ٢٢  │ ليدربورد منفصل: مستوى المادة + مستوى الخطة              │
│ ٢٣  │ التنافس فقط بين طلاب نفس الخطة                         │
│ ٢٤  │ الليدربورد: أعلى ٢٠ + ترتيب الطالب نفسه                │
│ ٢٥  │ الليدربورد يتحدث دورياً (الفترة يقررها الباك إند)       │
│ ٢٦  │ كاش أسئلة التوبيك كملفات جيسون على سيدي إن             │
│ ٢٧  │ ملف جيسون واحد لكل توبيك — نفس آلية بناء الهرمية       │
└─────┴──────────────────────────────────────────────────────────┘
```
