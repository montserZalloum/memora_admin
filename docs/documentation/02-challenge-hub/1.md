# مركز التحدي (Challenge Hub) — مرجع شامل

## الغرض

```
تحدي متسلسل يشبه الألعاب
الطالب يثبت إتقانه لكل توبيك واحد تلو الآخر
الأسئلة = ضع دائرة فقط (من Review Item)
```

## الهرمية

```
مركز التحدي
  │
  ├── تراك ١
  │    ├── وحدة ١
  │    │    ├── توبيك ١ ← آخر مستوى (لا يوجد دروس صغيرة)
  │    │    ├── توبيك ٢
  │    │    └── توبيك ٣
  │    └── وحدة ٢
  │         ├── توبيك ٤
  │         └── توبيك ٥
  └── تراك ٢
       └── ...

ملاحظة: التسلسل مأخوذ من نفس مصدر الهرمية العادية
```

## شروط فتح التوبيك

```
هل الطالب ختم هذا التوبيك في المسار العادي؟
  │
  ├── لا ← مقفل 🔒
  │         رسالة: "روح اختم الدرس أولاً"
  │
  └── نعم ← هل هذا أول توبيك بالوحدة؟
               │
               ├── نعم ← مفتوح 🔓
               │
               └── لا ← هل التوبيك السابق مختوم في مركز التحدي؟
                          │
                          ├── نعم ← مفتوح 🔓
                          └── لا ← مقفل 🔒
                                    رسالة: "اختم التوبيك السابق أولاً"
```

## آلية اللعب

```
الطالب يفتح مركز التحدي
  │
  ├── يشوف التراكات
  │    └── يختار تراك
  │         └── يشوف الوحدات
  │              └── يختار وحدة
  │                   └── يشوف التوبيكات (مفتوح / مقفل / مختوم)
  │                        └── يختار توبيك مفتوح
  │                             │
  │                             ▼
  │                     ┌────────────────────────┐
  │                     │ كل الأسئلة المتاحة     │
  │                     │ لهذا التوبيك           │
  │                     │ من Review Item         │
  │                     │ (ضع دائرة فقط)        │
  │                     └────────────────────────┘
  │                             │
  │                             ▼
  │                     الطالب يجاوب سؤال سؤال
  │                             │
  │                             ▼
  │                     ┌────────────────────────┐
  │                     │ النتيجة:               │
  │                     │ نسبة النجاح >= ٥٠٪     │
  │                     │ ← ناجح ✓ التوبيك يُختم│
  │                     │                        │
  │                     │ نسبة النجاح < ٥٠٪      │
  │                     │ ← راسب ✗ يقدر يعيد    │
  │                     └────────────────────────┘
  │
  └── توبيك واحد فقط بالمرة الواحدة
```

## عدد الأسئلة

```
كل الأسئلة المتاحة للتوبيك بدون تحديد عدد معين
لأن الفكرة = مراجعة شاملة لكل التوبيك
```

## التعامل مع الخوارزمية (FSRS)

```
كل سؤال يُرسل للخوارزمية بغض النظر عن النتيجة:

  الطالب جاوب صح ← يدخل FSRS بتقييم "جيد" ← الفترة تطول
  الطالب جاوب غلط ← يدخل FSRS بتقييم "أعد" ← يرجع بكرة بالمراجعة اليومية

هذا يحصل في كل محاولة — سواء نجح أو رسب بالتوبيك

السبب: الخوارزمية لازم تشوف الصورة الكاملة
       (الصح والغلط) عشان تكون دقيقة
```

## إعادة المحاولة

```
مسموح بعدد غير محدود من المحاولات

السيناريو:
  محاولة ١ ← رسب (٤٠٪) ← FSRS يستلم كل النتائج
  محاولة ٢ ← نجح (٧٠٪) ← FSRS يستلم كل النتائج ← التوبيك يُختم
  محاولة ٣ ← رسب (٣٠٪) ← FSRS يستلم كل النتائج ← التوبيك يبقى مختوم

┌──────────────────────────────────────────────────────┐
│                                                       │
│  النسبة المحفوظة للعرض = أعلى نسبة ناجحة (٧٠٪)     │
│  لا ترجع لراسب أبداً بعد النجاح                      │
│                                                       │
│  نتائج الخوارزمية = كل محاولة تُرسل كاملة            │
│  لأن الطالب لو نسي شيء بعد شهر الخوارزمية لازم تعرف │
│                                                       │
└──────────────────────────────────────────────────────┘
```

## تخزين المحاولات (للتحليل)

```
┌─────────────────────────────────────────────────┐
│  جدول محاولات التحدي (Challenge Attempt)        │
│                                                  │
│  ── الطالب                                      │
│  ── التوبيك                                     │
│  ── رقم المحاولة (١، ٢، ٣، ...)                │
│  ── عدد الأسئلة الكلي                           │
│  ── عدد الإجابات الصحيحة                        │
│  ── النسبة                                      │
│  ── نجح أو رسب                                  │
│  ── الوقت المستغرق                              │
│  ── التاريخ                                     │
│                                                  │
│  تشايلد تيبل — تفاصيل المحاولة:                │
│  ┌─────────────────────────────────────────┐    │
│  │  Challenge Attempt Detail               │    │
│  │  ── معرّف السؤال (item_id)              │    │
│  │  ── جاوب صح أو غلط                     │    │
│  └─────────────────────────────────────────┘    │
│                                                  │
└─────────────────────────────────────────────────┘

ملاحظة: هذا الجدول منفصل تماماً عن الخوارزمية
الخوارزمية تأخذ نتائجها مباشرة
هذا الجدول فقط للتحليل والعرض
```

## تقدم الطالب البصري

```
يُحسب من جهة التطبيق (كلاينت سايد)
لأن التطبيق يعرف أي توبيكات مختومة وأي لا

مثال:
  وحدة ١: ████░░░░ ٣/٥ توبيكات
  وحدة ٢: ░░░░░░░░ ٠/٤ توبيكات
```

## لا يؤثر على

```
  ✗ لا يؤثر على الإحصائيات العامة
  ✗ لا يؤثر على النقاط (XP)
  ✗ لا يؤثر على المتصدرين
  ✗ لا يؤثر على الستريك
  
  ✓ يؤثر فقط على FSRS (كل سؤال يُرسل للخوارزمية)
```

## ملخص القرارات

```
┌────┬────────────────────────────────────────────────────┐
│ ١  │ توبيك واحد فقط بالمرة الواحدة                     │
│ ٢  │ كل الأسئلة المتاحة للتوبيك (بدون تحديد عدد)      │
│ ٣  │ نسبة نجاح ٥٠٪ لختم التوبيك                       │
│ ٤  │ كل سؤال يُرسل للخوارزمية (صح وغلط)               │
│ ٥  │ إعادة المحاولة مسموحة بلا حدود                    │
│ ٦  │ أعلى نسبة ناجحة تُحفظ ولا ترجع لراسب             │
│ ٧  │ كل محاولة تُحفظ للتحليل                          │
│ ٨  │ التقدم البصري يُحسب من جهة التطبيق                │
│ ٩  │ لا تأثير على XP / متصدرين / ستريك / إحصائيات     │
│ ١٠ │ التسلسل من نفس مصدر الهرمية العادية               │
└────┴────────────────────────────────────────────────────┘
```
