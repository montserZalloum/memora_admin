# بنية المحتوى — المخطط العام (النسخة ٥ — النهائية)

## هرمية المحتوى

```
المادة (Subject)
 └── المسار (Track)
      └── الوحدة (Unit)
           └── التوبيك (Topic) ← يمثل الدرس الفعلي في الكتاب
                │
                └── دروس صغيرة (Lessons)
                     ├── الدرس ١
                     │    ├── مرحلة شرح (INFORMATION)
                     │    ├── مرحلة سؤال (QUESTION)
                     │    ├── مرحلة مطابقة (MATCHING)
                     │    └── مرحلة ملء فراغ (FILL_BLANK)
                     ├── الدرس ٢
                     └── الدرس ٣
```

## هرمية الأسئلة الوزارية (جدول منفصل)

```
المادة (Subject) ← نفس المادة لربط شرط الفتح
 └── وحدة وزارية
      └── أسئلة (تشايلد تيبل)
           ├── سؤال ١ (نوع: وزاري / بنك أسئلة)
           ├── سؤال ٢
           └── سؤال ٣
```

## قاعدة عرض الأسئلة

```
نفس السؤال يظهر في كل الأماكن بدون فلترة
لأن كل مكان له سياق مختلف:
  ── المراجعة اليومية = النظام يقرر (تثبيت بالذاكرة)
  ── ساحة التدريب = الطالب يقرر (تدريب حر — بدون أي تأثير)
  ── مركز التحدي = تحدي متسلسل (اختبار إتقان)
  ── الأسئلة الوزارية = محاكاة الامتحان الحقيقي
```

## حلقة التعلم الكاملة

```
    ┌────────────────────────────────────────────────────────┐
    │                                                         │
    │  ١. الذكاء الاصطناعي يولّد أسئلة ← Review Item        │
    │  ٢. الذكاء الاصطناعي يبني دروس تشير للأسئلة           │
    │                                                         │
    │  الطالب يدرس الدرس ← النتائج تدخل FSRS               │
    │       │                                                 │
    │       ▼                                                 │
    │  مركز التحدي ←── Review Item ──→ ساحة التدريب          │
    │       │                           (بدون FSRS)          │
    │       │ يرسل كل شيء للخوارزمية                         │
    │       │                                                 │
    │       ▼                                                 │
    │  Memory State (FSRS) ←── الأسئلة الوزارية              │
    │       │                   (ترسل كل شيء للخوارزمية)     │
    │       ▼                                                 │
    │  المراجعة اليومية                                       │
    │       │                                                 │
    │       ├── مصدر "درس" ← Review Item                     │
    │       └── مصدر "وزاري" ← الجدول الوزاري                │
    │                                                         │
    └────────────────────────────────────────────────────────┘
```

## ملخص القرارات العامة

```
┌────┬──────────────────────────────────────────────────────────┐
│ ١  │ Review Item هو المصدر — الدروس تشير إليه وليس العكس    │
│ ٢  │ الأسئلة تُولّد أولاً ثم الدروس تُبنى عليها              │
│ ٣  │ الجدول الوزاري منفصل تماماً عن Review Item              │
│ ٤  │ حقل نوع المصدر في Memory State يميّز "درس" عن "وزاري"  │
│ ٥  │ المراجعة اليومية تسحب من جدولين حسب المصدر              │
│ ٦  │ ساحة التدريب = صفر علاقة بالخوارزمية                    │
│ ٧  │ مركز التحدي + الوزاري = كل شيء يُرسل للخوارزمية        │
│ ٨  │ نفس السؤال يظهر في كل الأماكن بدون فلترة               │
│ ٩  │ جداول التحليل منفصلة لكل فيتشر                         │
│ ١٠ │ config_json يبقى كما هو بدون تغيير                      │
│ ١١ │ بنوك الأسئلة تُعامل معاملة الوزاري بحقل النوع           │
└────┴──────────────────────────────────────────────────────────┘
```
