# بنية المحتوى — نقطة مرجعية (النسخة ٤)

## هرمية المحتوى

```
المادة (Subject)
 └── المسار (Track)
      └── الوحدة (Unit)
           └── التوبيك (Topic) ← يمثل الدرس الفعلي في الكتاب
                │
                └── دروس صغيرة (Lessons)
                     ├── الدرس ١
                     │    ├── مرحلة شرح (INFORMATION)
                     │    ├── مرحلة سؤال (QUESTION)
                     │    ├── مرحلة مطابقة (MATCHING)
                     │    └── مرحلة ملء فراغ (FILL_BLANK)
                     ├── الدرس ٢
                     └── الدرس ٣
```

## هرمية الأسئلة الوزارية (منفصلة)

```
المادة (Subject) ← نفس المادة لربط شرط الفتح
 └── وحدة وزارية
      └── أسئلة (تشايلد تيبل)
           ├── سؤال ١ (سنة الامتحان، الدورة، ...)
           ├── سؤال ٢
           └── سؤال ٣
```

## قاعدة الأسئلة الخاطئة

```
سؤال خاطئ في أي مكان
         │
         ├── من ساحة التدريب ← يدخل Memory State بمصدر "درس"
         ├── من مركز التحدي  ← يدخل Memory State بمصدر "درس"
         └── من الأسئلة الوزارية ← يدخل Memory State بمصدر "وزاري"
                │
                ▼
    المراجعة اليومية تجيب الأسئلة المستحقة
         │
         ├── مصدر "درس" ← محتوى من Memora Review Item
         └── مصدر "وزاري" ← محتوى من الجدول الوزاري
```

## قاعدة عرض الأسئلة

```
نفس السؤال يظهر في كل الأماكن بدون فلترة
لأن كل مكان له سياق مختلف:
  ── المراجعة اليومية = النظام يقرر (تثبيت بالذاكرة)
  ── ساحة التدريب = الطالب يقرر (تدريب حر)
  ── مركز التحدي = تحدي متسلسل (اختبار إتقان)
  ── الأسئلة الوزارية = محاكاة الامتحان الحقيقي
```
