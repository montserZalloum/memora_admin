# بنية المحتوى — نقطة مرجعية (النسخة ٣)

## هرمية المحتوى

```
المادة (Subject)
 └── المسار (Track)
      └── الوحدة (Unit)
           └── التوبيك (Topic) ← يمثل الدرس الفعلي في الكتاب
                │
                └── دروس صغيرة (Lessons)
                     ├── الدرس ١
                     │    ├── مرحلة شرح (INFORMATION)
                     │    ├── مرحلة سؤال (QUESTION)
                     │    ├── مرحلة مطابقة (MATCHING)
                     │    └── مرحلة ملء فراغ (FILL_BLANK)
                     ├── الدرس ٢
                     └── الدرس ٣
```

## الأماكن الثلاثة — مقارنة

```
┌──────────────────┬──────────────────┬──────────────────┐
│  المراجعة اليومية │   ساحة التدريب    │   مركز التحدي    │
├──────────────────┼──────────────────┼──────────────────┤
│                  │                  │                  │
│ النظام يقرر     │ الطالب يقرر      │ تسلسل إجباري    │
│ متى تظهر الأسئلة │ شو يتدرب عليه   │ مثل الألعاب     │
│                  │                  │                  │
│ ١٠ أسئلة / مادة │ اختيار حر:       │ توبيك واحد      │
│ مع خيار إكمال   │ تراكات / وحدات / │ بالمرة الواحدة  │
│                  │ توبيكات متعددة   │                  │
│                  │                  │                  │
│ تستخدم FSRS     │ بدون FSRS       │ بدون FSRS       │
│ (تكرار متباعد)  │                  │                  │
│                  │                  │                  │
│ كل الأسئلة      │ التوبيكات        │ التوبيك ينفتح   │
│ من الدروس       │ المختومة فقط     │ بعد ختمه بالمسار │
│ المختومة        │                  │ العادي + ختم     │
│                  │                  │ التوبيك السابق   │
│                  │                  │ في مركز التحدي  │
│                  │                  │                  │
│                  │                  │ نسبة النجاح     │
│                  │                  │ ٥٠٪ لختم التوبيك│
│                  │                  │                  │
└──────────────────┴──────────────────┴──────────────────┘
```

## قاعدة الأسئلة الخاطئة

```
                    سؤال خاطئ
                       │
        ┌──────────────┼──────────────┐
        │              │              │
   ساحة التدريب   مركز التحدي   المراجعة اليومية
        │              │              │
        ▼              ▼              │
   يدخل FSRS     يدخل FSRS     موجود أصلاً
        │              │          بال FSRS
        ▼              ▼
   يظهر في المراجعة اليومية القادمة
```

## قاعدة عرض الأسئلة

```
نفس السؤال يظهر في كل الأماكن بدون فلترة
لأن كل مكان له سياق مختلف:
  ── المراجعة اليومية = النظام يقرر (تثبيت بالذاكرة)
  ── ساحة التدريب = الطالب يقرر (تدريب حر)
  ── مركز التحدي = تحدي متسلسل (اختبار إتقان)
```

## مسار فتح التوبيك في مركز التحدي

```
التوبيك ١ مختوم بالمسار العادي؟
  │
  ├── لا ← مقفل في مركز التحدي
  │
  └── نعم ← هل التوبيك السابق مختوم في مركز التحدي؟
               │
               ├── لا (أو هذا أول توبيك) ← مفتوح
               │
               └── نعم ← مفتوح
```
