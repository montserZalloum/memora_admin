# بنية المحتوى — نقطة مرجعية (النسخة ٤)

## هرمية المحتوى

```
المادة (Subject)
 └── المسار (Track)
      └── الوحدة (Unit)
           └── التوبيك (Topic) ← يمثل الدرس الفعلي في الكتاب
                │
                └── دروس صغيرة (Lessons)
                     ├── الدرس ١
                     │    ├── مرحلة شرح (INFORMATION)
                     │    ├── مرحلة سؤال (QUESTION)
                     │    ├── مرحلة مطابقة (MATCHING)
                     │    └── مرحلة ملء فراغ (FILL_BLANK)
                     ├── الدرس ٢
                     └── الدرس ٣
```

## وضعا التحدي المباشر

```
┌─────────────────────────────────┬─────────────────────────────────┐
│     وضع الامتحان (Exam)         │    وضع آخر صامد (Last Stand)    │
├─────────────────────────────────┼─────────────────────────────────┤
│                                 │                                 │
│ كل الأسئلة تُعرض دفعة واحدة   │ الأسئلة تُعرض سؤال بسؤال       │
│ وقت محدد للامتحان كامل         │ كل دور = سؤال واحد + وقت محدد  │
│ أو وقت لكل سؤال (اختياري)      │                                 │
│                                 │ نظام القلوب:                    │
│ الطالب يجاوب بأي ترتيب         │ ── إجابة خاطئة = خسارة قلب     │
│ ويقدم مرة واحدة               │ ── نفاد القلوب = إقصاء          │
│                                 │                                 │
│ النتيجة = (صحيح / كلي) × ١٠٠  │ WebSocket: بث مباشر لكل لاعب   │
│                                 │ (كل لاعب يرى حالته الخاصة)      │
│                                 │                                 │
│ REST + WebSocket                │ WebSocket إلزامي                │
│                                 │ (محرك أدوار يعمل على الخادم)    │
│                                 │                                 │
└─────────────────────────────────┴─────────────────────────────────┘
```

## قاعدة الأسئلة الخاطئة

```
                    سؤال خاطئ
                       │
        ┌──────────────┼──────────────┐
        │              │              │
   ساحة التدريب   مركز التحدي   المراجعة اليومية
        │              │              │
        ▼              ▼              │
   يدخل FSRS     يدخل FSRS     موجود أصلاً
        │              │          بال FSRS
        ▼              ▼
   يظهر في المراجعة اليومية القادمة


   ملاحظة: التحدي المباشر (Live Challenge) لا يغذي FSRS
   الأسئلة الخاطئة فيه تُسجل فقط ولا تدخل دورة التكرار المتباعد
```

## قاعدة عرض الأسئلة

```
نفس السؤال يظهر في كل الأماكن بدون فلترة
لأن كل مكان له سياق مختلف:
  ── المراجعة اليومية = النظام يقرر (تثبيت بالذاكرة)
  ── ساحة التدريب = الطالب يقرر (تدريب حر)
  ── مركز التحدي = تحدي متسلسل (اختبار إتقان)
  ── التحدي المباشر = حدث تنافسي مجدول (اختبار / إقصاء)
```

## مسار فتح التوبيك في مركز التحدي

```
التوبيك ١ مختوم بالمسار العادي؟
  │
  ├── لا ← مقفل في مركز التحدي
  │
  └── نعم ← هل التوبيك السابق مختوم في مركز التحدي؟
               │
               ├── لا (أو هذا أول توبيك) ← مفتوح
               │
               └── نعم ← مفتوح
```
