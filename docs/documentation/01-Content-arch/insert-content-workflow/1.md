# عملية إنشاء المحتوى — من الكتاب إلى الطالب

## الخطوة ١: توليد أسئلة ضع دائرة من الكتاب

```
┌──────────────────────────────────┐
│  الكتاب — توبيك: العواصم العربية  │
│                                    │
│  "عاصمة الأردن هي عمّان"          │
│  "عاصمة مصر هي القاهرة"           │
│  "عاصمة العراق هي بغداد"          │
└──────────────┬───────────────────┘
               │
               ▼
        ┌──────────────┐
        │ ذكاء اصطناعي │
        └──────┬───────┘
               │
               ▼
┌─────────────────────────────────────────────────────────┐
│              Review Item (جدول الأسئلة)                  │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │ سؤال ١ (item_id: UUID-001)                      │    │
│  │ ما هي عاصمة الأردن؟                             │    │
│  │ خيار ١: عمّان ✓  خيار ٢: دمشق  خيار ٣: بغداد  │    │
│  └─────────────────────────────────────────────────┘    │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │ سؤال ٢ (item_id: UUID-002)                      │    │
│  │ ما هي عاصمة مصر؟                                │    │
│  │ خيار ١: القاهرة ✓  خيار ٢: الإسكندرية  خيار ٣: أسوان │
│  └─────────────────────────────────────────────────┘    │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │ سؤال ٣ (item_id: UUID-003)                      │    │
│  │ ما هي عاصمة العراق؟                             │    │
│  │ خيار ١: بغداد ✓  خيار ٢: البصرة  خيار ٣: أربيل │    │
│  └─────────────────────────────────────────────────┘    │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## الخطوة ٢: بناء الدروس والمراحل من الأسئلة

```
┌─────────────────────────────────────────────────────────┐
│  الدرس الصغير ١: "تعرّف على العواصم العربية"            │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │ مرحلة ١ — شرح (INFORMATION)                     │    │
│  │ "العواصم هي المدن الرئيسية لكل دولة..."        │    │
│  │ لا ترتبط بأي Review Item (مرحلة قابلة للتخطي)  │    │
│  └─────────────────────────────────────────────────┘    │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │ مرحلة ٢ — ملء فراغ (FILL_BLANK)                │    │
│  │ "عاصمة الأردن هي ___ وعاصمة مصر هي ___"       │    │
│  │                                                  │    │
│  │ فراغ ١ (عمّان)  ──→ مرتبط بـ UUID-001          │    │
│  │ فراغ ٢ (القاهرة) ──→ مرتبط بـ UUID-002          │    │
│  └─────────────────────────────────────────────────┘    │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │ مرحلة ٣ — مطابقة (MATCHING)                     │    │
│  │ "طابق الدولة بعاصمتها"                          │    │
│  │                                                  │    │
│  │ الأردن ↔ عمّان   ──→ مرتبط بـ UUID-001          │    │
│  │ مصر ↔ القاهرة    ──→ مرتبط بـ UUID-002          │    │
│  │ العراق ↔ بغداد   ──→ مرتبط بـ UUID-003          │    │
│  └─────────────────────────────────────────────────┘    │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │ مرحلة ٤ — ضع دائرة (QUESTION)                  │    │
│  │ "ما هي عاصمة العراق؟"                           │    │
│  │ بغداد ✓ / البصرة / أربيل                        │    │
│  │                                                  │    │
│  │ السؤال كامل ──→ مرتبط بـ UUID-003               │    │
│  └─────────────────────────────────────────────────┘    │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## الخطوة ٣: ماذا يحصل عند لعب الدرس

```
الطالب يلعب الدرس
  │
  ├── مرحلة ١ (شرح) ← يقرأ ويتجاوز
  │
  ├── مرحلة ٢ (ملء فراغ)
  │    ├── فراغ ١ (عمّان) ← جاوب صح ← لا شيء
  │    └── فراغ ٢ (القاهرة) ← جاوب غلط ← UUID-002 يدخل FSRS
  │
  ├── مرحلة ٣ (مطابقة)
  │    ├── الأردن ↔ عمّان ← جاوب صح ← لا شيء
  │    ├── مصر ↔ القاهرة ← جاوب صح ← لا شيء
  │    └── العراق ↔ بغداد ← جاوب غلط ← UUID-003 يدخل FSRS
  │
  └── مرحلة ٤ (ضع دائرة)
       └── عاصمة العراق ← جاوب صح ← لا شيء
```

## الخطوة ٤: المراجعة اليومية بعد الدرس

```
المراجعة اليومية (اليوم التالي)
  │
  ├── UUID-002: ما هي عاصمة مصر؟ ← ضع دائرة
  │   (لأن الطالب غلط فيه بمرحلة ملء الفراغ)
  │
  └── UUID-003: ما هي عاصمة العراق؟ ← ضع دائرة
      (لأن الطالب غلط فيه بمرحلة المطابقة)

  ملاحظة: بغض النظر عن نوع المرحلة اللي غلط فيها الطالب
  المراجعة اليومية دائماً تعرض السؤال كضع دائرة
  لأنها تسحب مباشرة من Review Item
```

## الصورة الكاملة

```
                    ┌──────────┐
                    │ الكتاب   │
                    └────┬─────┘
                         │
                         ▼
                  ┌──────────────┐
                  │ ذكاء اصطناعي │
                  └──────┬───────┘
                         │
              ┌──────────┴──────────┐
              ▼                     ▼
   ┌──────────────────┐  ┌──────────────────────┐
   │   Review Item    │  │  دروس + مراحل        │
   │  (أسئلة ضع دائرة │  │  (تجربة تعليمية)     │
   │   = المصدر)      │  │  كل عنصر يشير إلى    │
   │                  │  │  Review Item بالمعرّف │
   └────────┬─────────┘  └──────────┬───────────┘
            │                       │
            │                       ▼
            │              الطالب يلعب الدرس
            │              يغلط بعناصر معينة
            │                       │
            │            ┌──────────┴──────────┐
            │            ▼                     ▼
            │    ┌──────────────┐    ┌──────────────────┐
            ├───→│المراجعة اليومية│   │  ساحة التدريب    │
            │    │ (ضع دائرة)  │    │  (ضع دائرة)     │
            │    └──────────────┘    └──────────────────┘
            │
            │    ┌──────────────────┐
            └───→│  مركز التحدي     │
                 │  (ضع دائرة)     │
                 └──────────────────┘
```
