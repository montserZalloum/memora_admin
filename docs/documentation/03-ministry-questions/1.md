# الأسئلة الوزارية وبنوك الأسئلة — مرجع شامل

## الغرض

```
صفحة مستقلة للطالب يتدرب على أسئلة وزارية سابقة وبنوك أسئلة
فيتشر منعزلة بالمحتوى والعرض عن باقي النظام
لكنها تغذّي الخوارزمية (FSRS) بالنتائج
```

## الهرمية (جدول منفصل)

```
الأسئلة الوزارية
  │
  ├── وحدة ١ (نفس تسمية وحدات المنهج — لكن جدول منفصل)
  │    └── أسئلة (تشايلد تيبل)
  │         ├── سؤال ١
  │         ├── سؤال ٢
  │         └── سؤال ٣
  │
  ├── وحدة ٢
  │    └── أسئلة
  │         ├── سؤال ٤
  │         └── سؤال ٥
  │
  └── وحدة ٣
       └── ...
```

## التمييز بين الأنواع

```
كل سؤال يحمل حقل "النوع":

  ├── "وزاري"     → سؤال من امتحان وزارة سابق
  └── "بنك أسئلة"  → سؤال من بنك أسئلة خارجي

الطالب يشوف تبويبين أو فلتر يختار منه
البنية والمنطق وشروط الفتح = نفس الشيء للنوعين
```

## شروط فتح الوحدة

```
هل الطالب ختم نفس الوحدة في المسار العادي؟
  │
  ├── لا ← مقفلة 🔒
  │         رسالة: "اختم الوحدة في التعلم الطبيعي أولاً"
  │
  └── نعم ← هل هذه أول وحدة؟
               │
               ├── نعم ← مفتوحة 🔓
               │
               └── لا ← هل الوحدة السابقة مختومة في الوزاري؟
                          │
                          ├── نعم ← مفتوحة 🔓
                          └── لا ← مقفلة 🔒
                                    رسالة: "اختم الوحدة السابقة أولاً"
```

## آلية اللعب

```
الطالب يفتح صفحة الأسئلة الوزارية
  │
  ├── يشوف الوحدات (مفتوحة / مقفلة / مختومة)
  │    └── يختار وحدة مفتوحة
  │         │
  │         ├── فلتر: وزاري / بنك أسئلة / الكل
  │         │
  │         ▼
  │    ┌────────────────────────┐
  │    │ كل الأسئلة المتاحة     │
  │    │ لهذه الوحدة            │
  │    │ من الجدول الوزاري      │
  │    │ (ضع دائرة فقط)        │
  │    └────────────────────────┘
  │         │
  │         ▼
  │    الطالب يجاوب سؤال سؤال
  │         │
  │         ▼
  │    ┌────────────────────────┐
  │    │ النتيجة:               │
  │    │ نسبة النجاح >= ٥٠٪     │
  │    │ ← ناجح ✓ الوحدة تُختم │
  │    │                        │
  │    │ نسبة النجاح < ٥٠٪      │
  │    │ ← راسب ✗ يقدر يعيد    │
  │    └────────────────────────┘
  │
  └── وحدة واحدة بالمرة الواحدة
```

## عدد الأسئلة

```
كل الأسئلة المتاحة للوحدة بدون تحديد عدد معين
```

## التعامل مع الخوارزمية (FSRS)

```
كل سؤال يُرسل للخوارزمية بغض النظر عن النتيجة:

  الطالب جاوب صح ← يدخل FSRS بتقييم "جيد" ← الفترة تطول
  الطالب جاوب غلط ← يدخل FSRS بتقييم "أعد" ← يرجع بكرة بالمراجعة اليومية

هذا يحصل في كل محاولة — سواء نجح أو رسب بالوحدة

┌───────────────────────────────────────────────────────┐
│  الربط مع الخوارزمية عبر حقل نوع المصدر              │
│  في جدول Memora Memory State                         │
│                                                       │
│  نوع المصدر = "وزاري"                                │
│  المراجعة اليومية تجيب محتوى السؤال من الجدول الوزاري │
│  وليس من Review Item                                 │
└───────────────────────────────────────────────────────┘
```

## إعادة المحاولة

```
مسموحة بعدد غير محدود

السيناريو:
  محاولة ١ ← رسب (٤٠٪) ← FSRS يستلم كل النتائج
  محاولة ٢ ← نجح (٧٠٪) ← FSRS يستلم كل النتائج ← الوحدة تُختم
  محاولة ٣ ← رسب (٣٠٪) ← FSRS يستلم كل النتائج ← الوحدة تبقى مختومة

┌──────────────────────────────────────────────────────┐
│  النسبة المحفوظة للعرض = أعلى نسبة ناجحة            │
│  لا ترجع لراسب أبداً بعد النجاح                      │
│                                                       │
│  نتائج الخوارزمية = كل محاولة تُرسل كاملة            │
└──────────────────────────────────────────────────────┘
```

## تخزين المحاولات (للتحليل — جدول منفصل)

```
┌─────────────────────────────────────────────────┐
│  جدول محاولات الوزاري (Ministry Attempt)        │
│                                                  │
│  ── الطالب                                      │
│  ── الوحدة الوزارية                             │
│  ── رقم المحاولة (١، ٢، ٣، ...)                │
│  ── عدد الأسئلة الكلي                           │
│  ── عدد الإجابات الصحيحة                        │
│  ── النسبة                                      │
│  ── نجح أو رسب                                  │
│  ── الوقت المستغرق                              │
│  ── التاريخ                                     │
│                                                  │
│  تشايلد تيبل — تفاصيل المحاولة:                │
│  ┌─────────────────────────────────────────┐    │
│  │  Ministry Attempt Detail                │    │
│  │  ── معرّف السؤال (item_id)              │    │
│  │  ── جاوب صح أو غلط                     │    │
│  └─────────────────────────────────────────┘    │
│                                                  │
│  ملاحظة: جدول منفصل عن جدول محاولات التحدي     │
│  لأن كل فيتشر ممكن تتطور بشكل مستقل           │
│                                                  │
└─────────────────────────────────────────────────┘
```

## لا يؤثر على

```
  ✗ لا يؤثر على الإحصائيات العامة
  ✗ لا يؤثر على النقاط (XP)
  ✗ لا يؤثر على المتصدرين
  ✗ لا يؤثر على الستريك

  ✓ يؤثر فقط على FSRS (كل سؤال يُرسل للخوارزمية)
```

## ملخص القرارات

```
┌────┬────────────────────────────────────────────────────┐
│ ١  │ جدول منفصل تماماً عن Review Item                  │
│ ٢  │ وحدة واحدة بالمرة الواحدة                         │
│ ٣  │ كل الأسئلة المتاحة للوحدة (بدون تحديد عدد)       │
│ ٤  │ نسبة نجاح ٥٠٪ لختم الوحدة                        │
│ ٥  │ كل سؤال يُرسل للخوارزمية (صح وغلط)               │
│ ٦  │ الربط مع FSRS عبر حقل نوع المصدر = "وزاري"       │
│ ٧  │ المراجعة اليومية تجيب المحتوى من الجدول الوزاري   │
│ ٨  │ إعادة المحاولة مسموحة بلا حدود                    │
│ ٩  │ أعلى نسبة ناجحة تُحفظ ولا ترجع لراسب             │
│ ١٠ │ كل محاولة تُحفظ في جدول تحليل منفصل              │
│ ١١ │ حقل النوع يميّز بين "وزاري" و"بنك أسئلة"         │
│ ١٢ │ لا تأثير على XP / متصدرين / ستريك / إحصائيات     │
│ ١٣ │ الإدخال عبر ذكاء اصطناعي مباشرة بدون دروس        │
└────┴────────────────────────────────────────────────────┘
```
