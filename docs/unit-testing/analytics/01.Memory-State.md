## Bugs and Weaknesses Found

1. **~~`_coerce_value` doesn't handle `decimal.Decimal`~~ — FIXED** — MariaDB `DECIMAL(21,9)` columns (`stability`, `difficulty`) return Python `Decimal` objects via `SSDictCursor`. The fix (`isinstance(val, decimal.Decimal): return float(val)`) is live in `exporter.py`. All `_apply_decimal_coerce_patch` monkeypatches have been removed from test files. `TestCoerceValueUnit` (13 tests) confirms the fix works natively.

2. **`_JOB_NAME_RE` silently skips alphanumeric job names** — `_process_pending_jobs` uses `re.compile(r"^ARCH-\d+$")` to validate job names (path-traversal guard). Jobs with names like `ARCH-MS-001` are silently skipped by the executor. Intentional security behavior; confirmed by `test_invalid_job_name_skipped_by_executor`.

3. **`create_season_archive_jobs` has no scope isolation** — queries ALL ended seasons in the live DB. In a shared test database where production seasons have also ended, this causes `IntegrityError` when a production-scope job already exists. Pre-existing DB-state issue (not introduced by new tests). Causes 8 pre-existing test failures.

4. **`_fail_job` WHERE guard is correct** — `WHERE name=%s AND status=%s` prevents wrong-state updates. Confirmed by `test_fail_job_guard_prevents_wrong_status_update`.

5. **`_log_delete_audit` non-blocking pattern verified** — the try/except swallows DB errors silently. Integration tests confirm it writes correctly when the DB is available.
