**Change 1: Replace duplicate constant definitions with import.**

Remove lines 65-68 (the local constant definitions with "must match FastAPI constants" comment):
```python

INTERACTION_BUFFER_KEY = "memora:buffer:interactions"
```

Replace with import from the canonical location:
```python
from fastapi_app.core.constants import (
    DIRTY_PROGRESS_KEY,
    DIRTY_WALLETS_KEY,
    INTERACTION_BUFFER_KEY,
)
```

Place this import after the existing `import frappe` and `import redis` imports (at the top of the file with other imports).

**Change 2: Fix LTRIM to use `inserted` count.**

In `flush_interaction_buffer()`, change line 342 from:
```python
r.ltrim(INTERACTION_BUFFER_KEY, count, -1)
```
to:
```python
r.ltrim(INTERACTION_BUFFER_KEY, inserted, -1)
```

Also add a warning log when `inserted < count` to surface partial flush failures. Add this BEFORE the ltrim call:
```python
if inserted < count:
    logger.warning(
        f"Partial flush: {inserted}/{count} interactions inserted, "
        f"{count - inserted} failed items remain in buffer for retry"
    )
    _write_debug_log(f"PARTIAL FLUSH: {inserted}/{count} inserted, {count - inserted} remain")
```

Update the existing debug log on line 341 from:
```python
_write_debug_log(f"Trimming {count} items from buffer...")
```
to:
```python
_write_debug_log(f"Trimming {inserted} items from buffer (of {count} fetched)...")
```

Do NOT change any other logic in sync.py. The `sync_dirty_progress` and `sync_dirty_wallets` functions remain unchanged. The `_parse_timestamp`, `_get_subject_lesson_count`, and `_log_sync` helpers remain unchanged.
