**File 3: `fastapi_app/api/deps.py`**

Add the `require_admin` dependency and related constant/type alias. Place these AFTER the `CurrentUser` type alias and BEFORE the `--- Service Dependencies ---` comment.

```python
# --- Admin Dependency ---

ADMIN_ROLE = "System Manager"


async def require_admin(user: CurrentUser) -> TokenPayload:
	"""Dependency that requires admin role. Raises 403 if not admin."""
	if getattr(user, "role", None) != ADMIN_ROLE:
		raise HTTPException(
			status_code=status.HTTP_403_FORBIDDEN,
			detail={"code": "ADMIN_REQUIRED", "message": "Admin role required"},
		)
	return user


RequireAdmin = Annotated[TokenPayload, Depends(require_admin)]
```

Uses `getattr(user, "role", None)` for extra safety in case old tokens without `role` are still in circulation.

No other changes to deps.py beyond what Plan 02 already did. The `require_admin` function is additive.
