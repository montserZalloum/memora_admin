<task type="auto">
  <name>Task 1: Consolidate deps.py service factories to use RedisClient sub-dependency</name>
  <files>fastapi_app/api/deps.py</files>
  <action>
Refactor ALL 16 service factory functions to use `RedisClient` as a parameter instead of constructing `redis.Redis(connection_pool=request.app.state.redis_pool)` directly. This leverages FastAPI's sub-dependency injection.

**Pattern -- factories WITHOUT FrappeClient:**

BEFORE:
```python
async def get_season_service(request: Request) -> SeasonService:
    """Get SeasonService with Redis from app state."""
    redis_client = redis.Redis(connection_pool=request.app.state.redis_pool)
    return SeasonService(redis_client)
```

AFTER:
```python
async def get_season_service(redis_client: RedisClient) -> SeasonService:
    """Get SeasonService with Redis from app state."""
    return SeasonService(redis_client)
```

Apply this pattern to: `get_season_service`, `get_device_service`, `get_game_session_service`, `get_leaderboard_service`, `get_stats_service`.

**Pattern -- factories WITH FrappeClient:**

BEFORE:
```python
async def get_access_service(request: Request) -> AccessService:
    """Get AccessService with Redis and FrappeClient from app state."""
    redis_client = redis.Redis(connection_pool=request.app.state.redis_pool)
    frappe_client = await get_frappe_client()
    return AccessService(redis_client, frappe_client=frappe_client)
```

AFTER:
```python
async def get_access_service(redis_client: RedisClient) -> AccessService:
    """Get AccessService with Redis and FrappeClient from app state."""
    frappe_client = await get_frappe_client()
    return AccessService(redis_client, frappe_client=frappe_client)
```

Apply this pattern to: `get_access_service`, `get_progress_service`, `get_wallet_service`, `get_settings_service`, `get_hierarchy_service`, `get_plan_service`, `get_profile_service`, `get_profile_page_service`, `get_catalog_service`, `get_purchase_service`, `get_review_service`.

**Also:** Since `Request` is no longer needed by any factory function, remove it from the imports if it is no longer used elsewhere in the file. Check first -- `Request` IS still used in `get_redis()` itself, so it stays in the imports.

The `get_redis` function itself, `RedisClient` type alias, `get_current_user`, `CurrentUser`, `get_frappe_client`, all gate dependencies (`require_season_access`, `require_content_access`, `require_double_gate`), and all `*Dep` type aliases remain UNCHANGED.

Do NOT change function signatures of the type aliases (e.g., `SeasonServiceDep = Annotated[SeasonService, Depends(get_season_service)]`).
