Currently they do unnecessary {"user": player_id} lookups that return nothing for PLAYER-##### profiles (the user field is being removed). This is the critical path for SC#2 (purchase flow, profile update, device removal all work for PLAYER-##### named profiles).

Output: 4 updated API files that work correctly with PLAYER-##### docname identity.
