<objective>
Migrate all 4 event handlers from old identity model (doc.user, frappe.cache()) to new identity model (doc.name/doc.player, get_fastapi_redis()) and remove the user field from Player Profile JSON schema.

Purpose: Event handlers are the Frappe-side writers that populate Redis keys consumed by FastAPI. Currently they write to wrong keys (doc.user = None for new players) and wrong Redis namespace (frappe.cache() adds site prefix). This is the critical path for SC#1 (subscription change syncs access grant) and SC#3 (profile_sync and plan_change_sync use get_fastapi_redis()).

Output: 4 updated event handlers + 1 updated JSON schema, all using PLAYER-##### docname identity and FastAPI Redis namespace.
</objective>

**access_sync.py** (on_subscription_change + on_subscription_deleted):
- SIMPLIFY: Remove the entire try/except block that does `frappe.get_doc("Memora Player Profile", player_id)` then `user_id = player_doc.user`. Instead use `user_id = doc.player` directly. The `doc.player` field on Memora Player Subscription IS the PLAYER-##### docname. No lookup needed.

**plan_change_sync.py** (on_player_profile_plan_changed):
- Full rewrite of Redis operations:
  1. Replace `cache = frappe.cache()` with `from memora_admin.events.access_sync import get_fastapi_redis` (at file top) and `r = get_fastapi_redis()`
  2. Replace `session_key = f"memora:session:{doc.user}"` with `session_key = f"memora:session:{doc.name}"`
  3. Replace `cache.delete_value(session_key)` with `r.delete(session_key)`
  4. Replace `"player_id": doc.user` with `"player_id": doc.name` in invalidation message
  5. Replace `cache.publish(...)` with `r.publish(...)`
  6. Update log message from `doc.user` to `doc.name`
- This is the two-pronged invalidation pattern (direct delete + pubsub) matching catalog_sync.py.
- Remove `import json` only if no longer needed (it IS still needed for json.dumps). Remove unused imports.

**profile_sync.py** (on_player_profile_updated):
- Full rewrite of Redis operations:
  1. Add `from memora_admin.events.access_sync import get_fastapi_redis` at file top
  2. Replace `cache = frappe.cache()` with `r = get_fastapi_redis()`
  3. Replace all 4 occurrences of `doc.user` with `doc.name`:
     - `redis_key = f"memora:profile:{doc.name}"`
     - `"player_id": doc.name` in profile_data
     - `"player_id": doc.name` in invalidation_msg
     - `frappe.logger().info(f"Profile {doc.name} synced to Redis")`
  4. Replace `cache.set_value(redis_key, json.dumps(profile_data), expires_in_sec=CACHE_TTL)` with `r.set(redis_key, json.dumps(profile_data), ex=CACHE_TTL)`
  5. Replace `cache.publish(...)` with `r.publish(...)`
- This follows the two-pronged pattern: direct SET with TTL + pubsub notification.
