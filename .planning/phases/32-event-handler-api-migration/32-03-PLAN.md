<objective>
Migrate 2 scheduled tasks from old identity model (pp.user in SQL, frappe.conf.redis_cache) to new identity model (pp.name in SQL, get_fastapi_redis() for profile cache).

Purpose: These background tasks silently fail for PLAYER-##### profiles. profile_cache.py queries `{"user": ["in", player_ids]}` which returns nothing for PLAYER-##### named profiles (user field is empty/None). fsrs_processor.py JOINs on `pp.user` which is NULL for new players, causing them to be excluded from FSRS processing entirely. Additionally, profile_cache.py uses `frappe.conf.redis_cache` which may not be the same Redis as FastAPI's -- changing to get_fastapi_redis() ensures profile cache keys are in the correct namespace.

Output: 2 updated scheduled task files that work correctly with PLAYER-##### identity.
</objective>
