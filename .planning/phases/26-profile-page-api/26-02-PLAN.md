```python
class ProfilePageService:
    """Aggregation service for profile page endpoints.

    Composes: WalletService (XP, streak), ProfileService (display_name, avatar),
    Redis leaderboard ZSETs (per-subject XP, weekly activity),
    Frappe APIs (mastery, avatar update), StatsService (items learned).
    """
```

**Constructor takes:**
- `redis_client: redis.Redis`
- `frappe_client: FrappeClient`
- `key_prefix: str = "memora:"`

**Methods to implement:**

1. **`async def get_hero(self, player_id: str) -> dict`**
   - Get wallet via `WalletService(self.redis, frappe_client=self.frappe).get_wallet(player_id)` to get total XP and streak
   - Get profile via `ProfileService(self.redis, self.frappe).get_profiles_batch([player_id])` to get display_name and avatar
   - Calculate level from total XP using `calculate_level()` from constants
   - Return dict with: display_name, avatar, level, level_title, current_xp, xp_in_level, xp_for_next_level, xp_level_start, xp_level_end
   - For xp_level_start: `LEVEL_THRESHOLDS[level - 1]`
   - For xp_level_end: `LEVEL_THRESHOLDS[level]` if level < len(LEVEL_THRESHOLDS) else 0

2. **`async def get_stats(self, player_id: str, subject_id: str | None = None) -> dict`**
   - **Streak**: Always global (from wallet). Call `WalletService(self.redis, frappe_client=self.frappe).get_wallet(player_id)` for streak.
   - **Total XP**:
     - If `subject_id` is None: Use wallet `xp` (global total)
     - If `subject_id` provided: Use `self.redis.zscore(f"{self.prefix}lb:alltime:subject:{subject_id}", player_id)` and `int(score)` to strip composite timestamp. Return 0 if None.
   - **Items learned**:
     - If `subject_id` provided: Get stats hash `memora:stats:{player_id}:{subject_id}:v1` field `completed` via `self.redis.hget()`. Fall back to 0.
     - If `subject_id` is None: Need to sum across all subjects. Use `self.redis.keys(f"{self.prefix}stats:{player_id}:*")` to find all stats hashes, then pipeline HGET `completed` from each. Sum them. If no keys found, return 0.
   - Return dict: subject (or None), streak, items_learned, total_xp

3. **`async def get_weekly_activity(self, player_id: str, subject_id: str | None = None) -> dict`**
   - Use `datetime.now(ZoneInfo("Asia/Amman"))` for current time
   - Calculate Monday of current week: `monday = now - timedelta(days=now.weekday())`
   - Build 7 Redis keys for Mon-Sun: `memora:lb:daily:{YYYY-MM-DD}` (global) or `memora:lb:daily:{YYYY-MM-DD}:subject:{subject_id}` (filtered)
   - Use Redis pipeline with 7 ZSCORE calls (single round-trip)
   - Extract XP with `int(score)` if score is not None, else 0
   - Return dict: subject (or None), week_start (Monday date string), days (list of {date, day_name, xp}), total_xp (sum)
   - Day names: use `day.strftime("%a")` for short English names (Mon, Tue, Wed, Thu, Fri, Sat, Sun)

4. **`async def get_mastery(self, player_id: str, subject_id: str | None = None) -> dict`**
   - Check Redis cache first: `memora:mastery:{player_id}:{subject_id or "all"}` with 5-min TTL
   - On cache hit: return parsed JSON
   - On cache miss: call Frappe API `memora_admin.api.profile.get_memory_mastery` with player_id and subject_id
   - Cache the result with `MASTERY_CACHE_TTL` (300s)
   - Return dict: subject (or None), mature, learning, new_items, total

5. **`async def update_avatar(self, player_id: str, avatar: str) -> dict`**
   - Call Frappe API `memora_admin.api.profile.update_player_avatar` with player_id and avatar
   - On success, invalidate profile cache: `self.redis.delete(f"{self.prefix}profile:{player_id}")`
   - Return the Frappe API result dict (avatar, success)
   - If Frappe returns an error (e.g., invalid avatar), the FrappeClient will raise an exception

6. **`async def get_avatar_options(self) -> list[str]`**
   - Call Frappe API `memora_admin.api.profile.get_avatar_options`
   - Return list of avatar strings

7. **`async def logout(self, player_id: str, device_id: str | None = None) -> dict`**
   - Import SessionService and DeviceService inline or accept as params -- for simplicity, instantiate inline:
     ```python
     from fastapi_app.services.session import SessionService
     from fastapi_app.services.device import DeviceService
     session_service = SessionService(self.redis)
     await session_service.invalidate_session(player_id)
     if device_id:
         device_service = DeviceService(self.redis, key_prefix=self.prefix)
         await device_service.remove_device(player_id, device_id)
     ```
   - Return `{"success": True, "message": "Logged out successfully"}`

**Important patterns to follow:**
- Use `structlog.get_logger(__name__)` for logging
- Log cache hits/misses for mastery endpoint
- Handle bytes from Redis (decode if isinstance bytes)
- Use `json.dumps/loads` for cache serialization (same as ReviewService pattern)
- For items_learned `KEYS` call: use `self.redis.keys()` which is acceptable here because the key space is small (one key per subject per player, typically 1-5 subjects). NOT the full `SCAN` pattern.
