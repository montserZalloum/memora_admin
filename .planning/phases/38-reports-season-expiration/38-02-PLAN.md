  <action>
    1. Create `memora_admin/tasks/season_expiration.py` with function `expire_season_cards()`:
       - Docstring: "Daily job: expire Available/Allocated cards linked to ended or unpublished seasons."
       - Get today's date: `today = frappe.utils.today()`
       - **Step 1:** Find batches with at least one grant linked to an ended or unpublished season:
         ```sql
         SELECT DISTINCT b.name as batch_name
         FROM `tabMemora Voucher Batch` b
         JOIN `tabMemora Voucher Batch Grant` bg ON bg.parent = b.name
         JOIN `tabMemora Product Grant` pg ON bg.product_grant = pg.name
         JOIN `tabMemora Academic Plan` ap ON pg.plan = ap.name
         JOIN `tabMemora Season` s ON ap.season = s.name
         WHERE b.status IN ('Generated', 'Active')
           AND (s.end_date < %s OR s.is_published = 0)
         ```
         Pass `(today,)` as params.
       - **Step 2:** If no batches found, log info and return early.
       - **Step 3:** For each batch, run direct SQL UPDATE:
         ```sql
         UPDATE `tabMemora Voucher Card`
         SET status = 'Expired', void_reason = 'Season Ended',
             modified = NOW(), modified_by = 'Administrator'
         WHERE batch = %s AND status IN ('Available', 'Allocated')
         ```
         CRITICAL: The `status IN ('Available', 'Allocated')` clause prevents touching terminal states (Redeemed, Void). These must NEVER be changed.
       - **Step 4:** Get affected row count via `frappe.db.sql("SELECT ROW_COUNT()")[0][0]` after each UPDATE.
       - **Step 5:** Wrap each batch in try/except. On exception, call `frappe.log_error(title=f"Season expiration failed for batch {batch_name}")`. Continue to next batch.
       - **Step 6:** After all batches processed, if any cards were expired, call `frappe.db.commit()`.
       - **Step 7:** Log final summary: total cards expired, number of batches processed.
       - Follow the existing task pattern from `voucher_cleanup.py` and `consignment_billing.py` (try/except per item, commit at end, structured logging).

    2. Update `memora_admin/hooks.py` -- add to `scheduler_events["cron"]`:

       - Place it after the existing voucher_cleanup entry (30 2 * * *) with comment: `# Daily at 01:05: Expire cards linked to ended/unpublished seasons`
       - Actually, place it BEFORE voucher_cleanup chronologically. Insert at the right position among existing cron entries. 01:05 comes after 00:15 (weekly leaderboard) and before 02:00 (consignment billing). Place it between the leaderboard and consignment entries.
