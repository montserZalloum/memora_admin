- `CACHE_TTL = 3600` (1 hour per success criteria)
- `_cache_key(self, player_id: str) -> str` returns `f"{self.prefix}profile:{player_id}"`

  - `display_name = f"Anonymous {player_id[-4:]}"` (per CONTEXT.md)
  - `avatar = "default_avatar"`
- `async def get_profiles_batch(self, player_ids: list[str]) -> dict[str, PlayerProfile]`:
  - Return empty dict if no player_ids
  - Build keys list with `_cache_key` for each player_id
  - Use `self.redis.pipeline()` with MGET for single round-trip
  - Parse cached JSON into PlayerProfile objects
  - Collect cache misses
  - If cache misses exist, call `_fetch_from_frappe_batch(cache_misses)`
  - For any still-missing profiles, apply fallback
  - Return dict mapping player_id -> PlayerProfile
- `async def _fetch_from_frappe_batch(self, player_ids: list[str]) -> dict[str, PlayerProfile]`:
  - Limit batch to 50 profiles to avoid timeouts (per RESEARCH.md pitfall)
  - Call `self.frappe.call("memora_admin.api.profile.get_profiles_batch", {"player_ids": player_ids[:50]})`
  - Parse response into PlayerProfile objects
  - Cache each fetched profile with TTL using pipeline SET
  - Return dict of fetched profiles
- `async def set_profile(self, player_id: str, display_name: str, avatar: str) -> None`:
  - Create PlayerProfile, serialize to JSON, SET with TTL
  - Used by cache push from Frappe hook
- `async def invalidate(self, player_id: str) -> None`:
  - DELETE the cache key
  - Used by pub/sub handler
