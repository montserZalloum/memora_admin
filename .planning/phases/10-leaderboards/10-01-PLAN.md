<task type="auto">
  <name>Task 2: Create LeaderboardService with ZSET operations</name>
  <files>fastapi_app/services/leaderboard.py</files>
  <action>
Create LeaderboardService following codebase patterns from services/wallet.py:

1. Constants at module level:
   - AMMAN_TZ = ZoneInfo("Asia/Amman")
   - LB_PREFIX = "memora:lb"
   - Key patterns: f"{LB_PREFIX}:alltime", f"{LB_PREFIX}:daily:{date}", f"{LB_PREFIX}:weekly:{week}"

2. compute_composite_score(xp: int, timestamp: float | None = None) -> float:
   - Per CONTEXT.md: "earlier achiever wins"
   - Formula: xp + (1.0 - (timestamp % 1_000_000_000) / 1_000_000_000)
   - Use time.time() if timestamp not provided
   - Docstring explaining the tie-breaking logic

3. LeaderboardService class with __init__(self, redis_client: redis.Redis):
   - _get_key(lb_type: str, subject_id: str | None = None) -> str
     - Generate correct key based on type and optional subject
     - Daily: use datetime.now(AMMAN_TZ).strftime("%Y-%m-%d")
     - Weekly: use datetime.now(AMMAN_TZ).strftime("%G-W%V") (ISO week)
     - All-time: no date suffix
     - Subject: append :subject:{subject_id} if provided

4. get_top(lb_type: str, limit: int = 10, subject_id: str | None = None) -> list[dict]:
   - ZRANGE with desc=True, withscores=True
   - Extract XP from composite score (integer part)
   - Compute dense ranks (same score = same rank)
   - Return list of {rank, player_id, xp} dicts

5. get_my_rank(player_id: str, lb_type: str, subject_id: str | None = None, neighbor_count: int = 2) -> dict | None:
   - ZREVRANK with withscore=True to get position
   - Handle unranked users: return rank = total + 1, xp = 0, neighbors = []
   - Use ZCOUNT to compute dense rank (count scores strictly greater)
   - Get neighbors via ZRANGE around position
   - Calculate xp_to_next from player above
   - Return {rank, xp, xp_to_next, neighbors} dict

6. update_leaderboards(player_id: str, xp_amount: int, new_total_xp: int, subject_id: str | None = None) -> None:
   - All-time: ZADD with composite score (using new_total_xp)
   - Daily: ZINCRBY with xp_amount
   - Weekly: ZINCRBY with xp_amount
   - If subject_id provided, update subject-specific boards too
   - Use structlog for debug logging

Include proper type hints, docstrings explaining CONTEXT.md decisions, and follow the error handling patterns from wallet.py.
