Create GameSessionService following DeviceService and WalletService patterns:

1. **Lua Script (START_SESSION_SCRIPT)** - Atomic session start that force-closes any existing:
   ```lua
   -- KEYS[1] = memora:gamesession:{user_id}
   -- ARGV[1..6] = session_id, lesson_id, subject_id, device_id, timestamp, ttl

   -- Delete any existing session (force-close, no notification per CONTEXT.md)
   redis.call('DEL', KEYS[1])

   -- Create new session hash with all fields
   redis.call('HSET', KEYS[1],
       'session_id', ARGV[1],
       'lesson_id', ARGV[2],
       'subject_id', ARGV[3],
       'device_id', ARGV[4],
       'started_at', ARGV[5])

   -- Set TTL (1 hour)
   redis.call('EXPIRE', KEYS[1], ARGV[6])

   return {1, ARGV[1]}
   ```

2. **GameSessionService class**:
   - `__init__(self, redis_client: redis.Redis, key_prefix: str = "memora:")` - Store redis client and prefix, init _start_script = None
   - `_session_key(self, user_id: str) -> str` - Return f"{self.prefix}gamesession:{user_id}"
   - `async _get_start_script(self)` - Lazy-load and cache Lua script (pattern from WalletService._get_streak_script)
   - `async start_session(self, user_id: str, lesson_id: str, subject_id: str, device_id: str | None = None) -> str`:
     * Generate session_id = str(uuid.uuid4())
     * Generate timestamp = datetime.now(timezone.utc).isoformat()
     * Execute Lua script with GAME_SESSION_TTL
     * Log with structlog: session_started event
     * Return session_id
   - `async get_active_session(self, user_id: str) -> GameSession | None`:
     * HGETALL on session key
     * Return None if empty
     * Return GameSession.from_redis_hash(data)
   - `async end_session(self, user_id: str) -> GameSession | None`:
     * Get active session first (for return value)
     * DELETE session key
     * Log session_ended event
     * Return the session that was ended (or None if no session)
   - `async has_active_session(self, user_id: str) -> bool`:
     * EXISTS on session key (O(1) check)
