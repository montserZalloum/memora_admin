  <name>Task 2: Create sessions endpoint module</name>
  <files>fastapi_app/api/v1/endpoints/sessions.py</files>
  <action>
Create sessions.py with POST /sessions/start and POST /sessions/end endpoints:

**Imports:**
```python
import json
from fastapi import APIRouter, HTTPException, Header, status
import structlog

from fastapi_app.api.deps import (
    AccessServiceDep,
    CurrentUser,
    GameSessionServiceDep,
    HierarchyServiceDep,
    ProgressServiceDep,
    SettingsServiceDep,
    WalletServiceDep,
    RedisClient,
)
from fastapi_app.core.constants import INTERACTION_BUFFER_KEY
from fastapi_app.models.game_session import (
    EndSessionRequest,
    EndSessionResponse,
    StartSessionRequest,
    StartSessionResponse,
)
```

**Router setup:**
```python
logger = structlog.get_logger()
router = APIRouter(prefix="/sessions", tags=["sessions"])
```

**POST /sessions/start endpoint:**
- Parameters: request: StartSessionRequest, user: CurrentUser, game_session_service: GameSessionServiceDep, hierarchy_service: HierarchyServiceDep, access_service: AccessServiceDep, x_device_id: str | None = Header(None, alias="X-Device-ID")
- Validate subject exists via hierarchy_service.get_hierarchy(request.subject_id) - 404 if not found
- Validate lesson exists in hierarchy via hierarchy.find_lesson(request.lesson_id) - 404 if not found
- Check access via access_service.check_access(user.sub, f"SUB-{request.subject_id}") - 403 if no access
- Call game_session_service.start_session(user.sub, request.lesson_id, request.subject_id, x_device_id)
- Log session_started with user_id, lesson_id, subject_id
- Return StartSessionResponse(session_id=session_id, lesson_id=request.lesson_id)

**POST /sessions/end endpoint:**
- Parameters: request: EndSessionRequest, user: CurrentUser, game_session_service: GameSessionServiceDep, hierarchy_service: HierarchyServiceDep, progress_service: ProgressServiceDep, wallet_service: WalletServiceDep, settings_service: SettingsServiceDep, redis_client: RedisClient
- Get active session via game_session_service.get_active_session(user.sub)
- If no session, raise HTTPException 403 with code "NO_ACTIVE_SESSION", message "No active lesson session"
- Get hierarchy for session.subject_id (use cached session data, no additional param needed)
- Find lesson in hierarchy to get bit_index and xp
- Push stage analytics to interaction buffer (RPUSH):
  ```python
  for stage in request.stages:
      interaction = {
          "player": user.sub,
          "lesson": session.lesson_id,
          "stage_id": stage.stage_id,
          "event_type": "Completed",
          "time_spent": stage.time_spent,
          "errors_count": stage.fail_count,
          "timestamp": stage.completed_at,
          "metadata": stage.metadata,
      }
      await redis_client.rpush(INTERACTION_BUFFER_KEY, json.dumps(interaction))
  ```
- End session via game_session_service.end_session(user.sub)
- Mark lesson complete via progress_service.complete_lesson (same pattern as progress.py)
- Get settings, update streak, calculate XP, award XP (copy logic from progress.py complete_lesson endpoint)
- Import calculate_xp_award from progress module or inline the calculation
- Log session_ended with full details
- Return EndSessionResponse with xp_awarded, is_replay, streak

**Helper - XP calculation (inline or import):**
Either import from progress.py:
```python
from fastapi_app.api.v1.endpoints.progress import calculate_xp_award
```
Or copy the function inline (simpler, avoids circular imports).
