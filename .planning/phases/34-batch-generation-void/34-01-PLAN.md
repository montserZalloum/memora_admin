  <action>
    **1. Create `services/voucher/__init__.py`** (empty).

    **2. Create `services/voucher/crypto.py`** with:

    - Constants: `HKDF_SALT = b"memora-voucher-export-v1"`, `HKDF_INFO = b"fernet-encryption-key"` (fixed, versioned, not secret)
    - `get_fernet_key(hmac_secret: str) -> bytes`: Derive a 32-byte key from the HMAC secret using HKDF-SHA256 with the fixed salt and info, then base64url-encode for Fernet compatibility. Uses `cryptography.hazmat.primitives.kdf.hkdf.HKDF` with `hashes.SHA256()`, `length=32`.
    - `get_fernet(hmac_secret: str) -> Fernet`: Returns a `cryptography.fernet.Fernet` instance using the derived key.
    - `encrypt_data(data: bytes, hmac_secret: str) -> bytes`: Encrypt raw bytes using Fernet.
    - `decrypt_data(encrypted: bytes, hmac_secret: str) -> bytes`: Decrypt Fernet-encrypted bytes.

    **3. Create `services/voucher/generator.py`** with:

    - Constants: `PIN_ALPHABET = "ABCDEFGHJKMNPQRSTUVWXYZ23456789"` (30 chars, excludes ambiguous 0/O, 1/I/L)
    - `generate_pin(length: int = 12) -> str`: Generate a cryptographically secure PIN using `secrets.choice()` for each character. Never use `random.choice()`.
    - `compute_hmac(pin: str, secret: str) -> str`: Compute HMAC-SHA256 hex digest of the PIN using the server-side secret. Uses `hmac.new(secret.encode("utf-8"), pin.encode("utf-8"), hashlib.sha256).hexdigest()`.
    - `reserve_serial_block(count: int) -> list[str]`: Reserve a block of sequential serial numbers atomically via `tabSeries`. Execute `SELECT current FROM tabSeries WHERE name = 'VCH-SERIAL' FOR UPDATE`, then either UPDATE or INSERT. Return list of `VCH-{i:06d}` strings from `start` to `start + count - 1`. Single lock acquisition for the entire block -- no per-card locking.
    - `build_export_csv(cards_data: list[dict], product_names: str, face_value: str) -> bytes`: Build a CSV in memory with columns: serial_no, pin, product_names, face_value. Each dict in cards_data has keys "serial_no" and "pin" (plaintext). Returns UTF-8 encoded bytes. Uses `csv.writer` with `io.StringIO`.
    - `create_encrypted_export(csv_bytes: bytes, hmac_secret: str) -> bytes`: Encrypt the CSV bytes using the Fernet instance from `crypto.py`. Returns encrypted bytes ready for file storage.

    **Type hints:** Use Python 3.10+ syntax (`list[str]` not `List[str]`).
    **Imports:** Use `from __future__ import annotations` if needed for forward references.
  </action>
