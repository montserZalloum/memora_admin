  <action>
    **1. Add to `api/voucher.py` -- three new whitelisted methods:**

    **a) `export_for_print(batch_name: str)`** -- returns decrypted CSV as a file download:
    - Decorated with `@frappe.whitelist()`
    - Permission check: `if "System Manager" not in frappe.get_roles(): frappe.throw("Only System Manager can export", frappe.PermissionError)`
    - Load batch doc, verify `encrypted_file_url` exists (throw "No export file available" if not)
    - Read the encrypted file from disk: `frappe.get_site_path("private", "files", filename)` where filename is extracted from encrypted_file_url. Use careful path construction -- the `file_url` from save_file is typically `/private/files/filename.enc`, so strip leading slash and use `frappe.get_site_path()` to get the absolute path.
    - Decrypt using `decrypt_data(encrypted_bytes, frappe.conf.get("voucher_hmac_secret"))` from crypto.py
    - Log the export in the batch's export_log child table:
      ```python
      batch.append("export_log", {
          "exported_by": frappe.session.user,
          "exported_at": frappe.utils.now(),
          "card_count": batch.generated_count,
      })
      batch.save(ignore_permissions=True)
      frappe.db.commit()
      ```
    - Set response headers for CSV download:
      ```python
      frappe.local.response.filename = f"{batch_name}_pins.csv"
      frappe.local.response.filecontent = csv_bytes
      frappe.local.response.type = "download"
      ```

    **b) `void_batch(batch_name: str, void_reason: str)`** -- void all non-final cards and close batch:
    - Decorated with `@frappe.whitelist()`
    - Validate: `void_reason` is non-empty after strip (throw "Void reason is required")
    - Load batch doc, verify status is NOT "Closed" and NOT "Draft" (throw "Cannot void a Draft batch -- no cards exist" and "Batch is already Closed")
    - Void all non-terminal cards via direct SQL UPDATE (fast, avoids ORM overhead for potentially 1,000 cards):
      ```python
      frappe.db.sql("""
          UPDATE `tabMemora Voucher Card`
          SET status = 'Void', void_reason = %s, modified = NOW(), modified_by = %s
          WHERE batch = %s AND status IN ('Available', 'Allocated')
      """, (void_reason, frappe.session.user, batch_name))
      ```
    - Count voided cards: `frappe.db.count("Memora Voucher Card", {"batch": batch_name, "status": "Void"})`
    - Delete encrypted export file if it exists:
      - Find the File doc: `frappe.db.get_value("File", {"file_url": batch.encrypted_file_url, "attached_to_doctype": "Memora Voucher Batch", "attached_to_name": batch_name}, "name")`
      - If found: `frappe.delete_doc("File", file_name, ignore_permissions=True)` (this also deletes the physical file)
      - Clear `batch.encrypted_file_url`
    - Update batch: set `voided_count`, `status = "Closed"`, `void_reason`, save with `ignore_permissions=True`
    - Commit: `frappe.db.commit()`
    - Return `{"voided_count": voided_count, "status": "Closed"}`

    **c) `void_card(card_name: str, void_reason: str)`** -- void a single card:
    - Decorated with `@frappe.whitelist()`
    - Validate: `void_reason` is non-empty after strip
    - Load card doc, verify status is in ("Available", "Allocated") -- throw descriptive error for terminal states
    - Set `card.status = "Void"`, `card.void_reason = void_reason`
    - Save with `ignore_permissions=True`
    - Update the parent batch's voided_count: increment by 1 via `frappe.db.set_value("Memora Voucher Batch", card.batch, "voided_count", frappe.db.count("Memora Voucher Card", {"batch": card.batch, "status": "Void"}))`
    - Commit: `frappe.db.commit()`
    - Return `{"status": "Void", "card": card_name}`

    **3. Create `memora_admin/memora_admin/tasks/voucher_cleanup.py`:**

    - Find all Voucher Batches that have `encrypted_file_url` set (not empty/null)
    - For each batch: get the File doc by `file_url`, check if `creation` is older than 30 days

    - Log: `frappe.logger().info(f"Deleted expired export for batch {batch_name} (created {creation})")`
    - Wrap each batch cleanup in try/except to handle individual failures without stopping the task
