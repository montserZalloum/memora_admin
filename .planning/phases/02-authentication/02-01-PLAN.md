**Create fastapi_app/core/security.py with JWT utilities using PyJWT (NOT python-jose):**

1. Import `jwt` from PyJWT, `datetime`, `timezone`, `timedelta`, `uuid`
2. Import `get_settings` from config

**create_access_token function:**
- Parameters: user_id (str), email (str), role (str), timezone_str (str), display_name (str), family_id (str), expires_delta (optional timedelta, default 15 min from settings)
- Create payload with: sub=user_id, email, role, tz=timezone_str, name=display_name, fid=family_id, type="access", iat=now, exp=now+expires_delta, jti=uuid4
- Encode with jwt.encode(payload, settings.jwt_secret, algorithm=settings.jwt_algorithm)
- Return encoded token string

**create_refresh_token function:**
- Parameters: user_id (str), family_id (str), expires_delta (optional timedelta, default 30 days from settings)
- Create minimal payload: sub=user_id, fid=family_id, type="refresh", iat=now, exp=now+expires_delta, jti=uuid4
- Encode and return token string

**decode_token function:**
- Parameters: token (str), verify_type (optional str, e.g., "access" or "refresh")
- Use jwt.decode with algorithms=[settings.jwt_algorithm] and options={"require": ["sub", "exp", "type", "fid"]}
- If verify_type provided, check payload["type"] matches, raise jwt.InvalidTokenError if mismatch
- Return decoded payload dict
- Let jwt.ExpiredSignatureError and jwt.InvalidTokenError propagate (caller handles)

**IMPORTANT:** Use `datetime.now(tz=timezone.utc)` for all timestamps (not datetime.utcnow() which is deprecated).

```python
import httpx
from typing import Optional
from fastapi_app.models.auth import FrappeUser

class FrappeAuthService:
    """Authenticate against Frappe server via REST API."""

    def __init__(self, frappe_url: str, timeout: float = 10.0):
        self.frappe_url = frappe_url.rstrip("/")
        self.timeout = timeout

    async def verify_credentials(self, email: str, password: str) -> Optional[FrappeUser]:
        """
        Verify credentials via Frappe login API.
        Returns FrappeUser on success, None on failure.

        Per CONTEXT.md: Uses Frappe's auth (respects hooks, validations).
        """
```

**Implementation steps:**
1. Create async httpx.AsyncClient with timeout
2. POST to `{frappe_url}/api/method/login` with json={"usr": email, "pwd": password}
3. If status != 200, return None (don't reveal why auth failed)
4. GET `{frappe_url}/api/method/frappe.auth.get_logged_user` with cookies from login response
5. GET `{frappe_url}/api/resource/User/{user}` to get full profile (full_name, user_type, time_zone)
6. In finally block, attempt logout: GET `{frappe_url}/api/method/logout`
7. Wrap all in try/except httpx.RequestError -> return None
8. Return FrappeUser with data from profile, or minimal data if profile fetch fails

**IMPORTANT:**
- Use `async with httpx.AsyncClient(timeout=self.timeout) as client:` for proper cleanup
- Don't log failed credentials per CONTEXT.md
- Return None on any failure (generic response)
