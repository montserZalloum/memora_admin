  <files>memora_admin/memora_admin/api/allocation.py</files>
  <action>
Create `memora_admin/memora_admin/api/allocation.py` with four `@frappe.whitelist()` methods:

**1. `fill_cards(allocation_name: str, quantity: int = 0) -> dict`**
- Validate allocation is in Draft status
- If `allocation_type == "Allocate"`: query cards from `frappe.db.get_list("Memora Voucher Card", filters={"batch": alloc.batch, "status": "Available"}, fields=["name"], order_by="name asc", page_length=quantity or 0, ignore_permissions=True)`
- If `allocation_type == "Return"`: query cards with `filters={"batch": alloc.batch, "status": "Allocated", "library": alloc.customer}`, same fields/ordering
- Clear existing `alloc.allocation_cards = []`
- Append each card: `alloc.append("allocation_cards", {"voucher_card": card.name})`
- `alloc.save(ignore_permissions=True)` then `frappe.db.commit()`
- Return `{"filled_count": len(cards)}`
- Cast `quantity` to `int` (Frappe passes strings from JS). If `quantity <= 0`, pass `page_length=0` (meaning all available).

**2. `submit_allocation(allocation_name: str) -> dict`**
- Validate allocation is in Draft status
- Validate `alloc.allocation_cards` is not empty (throw "No cards in allocation. Use Fill Cards first.")
- Validate all cards in child table belong to the allocation's batch: query each card's batch and compare. If any mismatch, throw error.
- Read `requires_approval = frappe.db.get_value("Customer", alloc.customer, "voucher_requires_approval")`
- If `requires_approval` (truthy): set `alloc.status = "Pending Approval"`, save, commit, return `{"status": "Pending Approval"}`
- If NOT requires_approval: set `alloc.status = "Approved"`, save. Then set `alloc.status = "Completed"`, save, commit, return `{"status": "Completed"}`
- The two-step (Approved -> Completed) for auto-approve follows the VALID_TRANSITIONS: Draft->Approved->Completed. The `on_update` hook fires on the Completed save and applies card updates.

**3. `approve_allocation(allocation_name: str) -> dict`**
- Validate allocation is in "Pending Approval" status
- Set `alloc.status = "Approved"`, save
- Then set `alloc.status = "Completed"`, save, commit
- Return `{"status": "Completed"}`

**4. `reject_allocation(allocation_name: str, reject_reason: str = "") -> dict`**
- Validate allocation is in "Pending Approval" status
- Set `alloc.status = "Rejected"`, save, commit
- Optionally store reject_reason in `alloc.notes` if provided
- Return `{"status": "Rejected"}`

**Patterns to follow** (from `api/voucher.py`):
- Always `frappe.db.commit()` at end of each method
- Use `frappe.throw()` for validation errors with `frappe.ValidationError`
- Use `frappe.get_doc()` to load the allocation document

**Card batch validation in submit_allocation:**

**Add `on_update` method:**
```python
def on_update(self):
    if not self.has_value_changed("status"):
        return
    if self.status == "Completed":
        if self.allocation_type == "Allocate":
            self._apply_allocation()
        elif self.allocation_type == "Return":
            self._apply_return()
        self._update_batch_counters()
```

**Add `_apply_allocation` method:**
- Get card names from `self.allocation_cards`
- If no cards, return early
- Build SQL placeholders: `", ".join(["%s"] * len(card_names))`
- Execute direct SQL UPDATE:
```sql
UPDATE `tabMemora Voucher Card`
SET status = 'Allocated', library = %s, allocation = %s, sale_model = %s,
    modified = NOW(), modified_by = %s
WHERE name IN ({placeholders}) AND status IN ('Available', 'Allocated')
```
- Parameters: `[self.customer, self.name, self.sale_model, frappe.session.user] + card_names`
- Note: `status IN ('Available', 'Allocated')` supports both fresh allocation (Available) and re-allocation (Allocated from another library). This is per research decision #3.
- After UPDATE, call `self._activate_batch_if_needed()`

**Add `_apply_return` method:**
- Get card names from `self.allocation_cards`
- If no cards, return early
- Execute direct SQL UPDATE:
```sql
UPDATE `tabMemora Voucher Card`
SET status = 'Available', library = NULL, allocation = NULL,
    sale_model = NULL, return_allocation = %s,
    modified = NOW(), modified_by = %s
WHERE name IN ({placeholders}) AND status = 'Allocated'
```
- Parameters: `[self.name, frappe.session.user] + card_names`
- Note: Only targets `status = 'Allocated'` cards (returns only affect allocated cards).

**Add `_update_batch_counters` method:**
- Count allocated cards: `frappe.db.count("Memora Voucher Card", {"batch": self.batch, "status": "Allocated"})`
- Update batch: `frappe.db.set_value("Memora Voucher Batch", self.batch, "allocated_count", allocated_count, update_modified=True)`

**Add `_activate_batch_if_needed` method:**
- Only relevant for Allocate type
- Read batch status: `frappe.db.get_value("Memora Voucher Batch", self.batch, "status")`
- If status is "Generated": `frappe.db.set_value("Memora Voucher Batch", self.batch, "status", "Active", update_modified=True)`
- This transitions the batch from Generated -> Active on first allocation (per research finding #8)

**Also add `_validate_cards_belong_to_batch` to the existing `validate` method:**
Add after `self._update_quantity()`:

self._validate_cards_belong_to_batch()

The validation method:
```python
def _validate_cards_belong_to_batch(self):
    if not self.allocation_cards or not self.batch:
        return
    card_names = [row.voucher_card for row in self.allocation_cards if row.voucher_card]
    if not card_names:
        return
    mismatched = frappe.db.get_all(
        "Memora Voucher Card",
        filters={"name": ["in", card_names], "batch": ["!=", self.batch]},
        pluck="name",
    )
    if mismatched:
        frappe.throw(
            f"Cards {', '.join(mismatched)} do not belong to batch {self.batch}.",
            frappe.ValidationError,
        )
```
