**fastapi_app/core/ws_manager.py** - Per-user WebSocket ConnectionManager:

```python
class ConnectionManager:
    def __init__(self):
        self._connections: dict[str, set[WebSocket]] = defaultdict(set)
        self._lock = asyncio.Lock()
```

Methods:
- `async connect(user_id: str, websocket: WebSocket) -> bool`: Accept WebSocket, add to user's connection set. Return `True` if this is the first connection for user (caller should subscribe to pub/sub). Use async lock for thread safety.
- `async disconnect(user_id: str, websocket: WebSocket) -> bool`: Remove WebSocket from user's set. If set becomes empty, delete the key. Return `True` if this was the last connection for user (caller should unsubscribe from pub/sub). Use async lock.
- `async send_to_user(user_id: str, message: str) -> int`: Send text message to ALL WebSocket connections for the user. Catch exceptions per-connection (don't let one broken connection prevent others from receiving). Return count of successful sends. Log failed sends at debug level.
- `@property active_users -> int`: Return count of users with active connections (for health/metrics).
- `@property active_connections -> int`: Return total connection count across all users.

Use `structlog` for logging. Import from `collections import defaultdict`. Use `asyncio.Lock`.

```python
    payload: SubscriptionNotification
```
