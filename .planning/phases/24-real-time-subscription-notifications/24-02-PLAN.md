Implementation steps inside the endpoint:

a) **Authenticate BEFORE accepting** the WebSocket:
   - Call `decode_token(token, verify_type="access")` inside try/except
   - On `jwt.ExpiredSignatureError` or `jwt.InvalidTokenError` or any Exception: close with `websocket.close(code=status.WS_1008_POLICY_VIOLATION)` and return
   - Extract `user_id = payload["sub"]`

b) **Get ConnectionManager from app state:**
   ```python
   ws_manager: ConnectionManager = websocket.app.state.ws_manager
   ```

c) **Connect:**
   ```python
   is_first = await ws_manager.connect(user_id, websocket)
   ```

d) **If first connection, subscribe to user's Redis pub/sub channel:**
   - Get the notification pubsub object from app state: `notify_pubsub = websocket.app.state.notify_pubsub`
   - Subscribe: `await notify_pubsub.subscribe(f"memora:notify:{user_id}")`
   - Log at info level: `ws_connected`, user_id, is_first

e) **Keep connection alive with a receive loop:**
   ```python
   try:
       while True:
           # Wait for client messages (pings/pongs handled by protocol)
           # We don't expect client to send data, but must await to detect disconnect
           await websocket.receive_text()
   except WebSocketDisconnect:
       pass
   finally:
       is_last = await ws_manager.disconnect(user_id, websocket)
       if is_last:
           try:
               await notify_pubsub.unsubscribe(f"memora:notify:{user_id}")
           except Exception:
               pass
       logger.info("ws_disconnected", user_id=user_id, is_last=is_last)
   ```

**3. Modify `fastapi_app/core/pubsub.py`:**

The existing `start_pubsub_listener` subscribes to `memora:cache:invalidate` only. We need a SEPARATE listener for per-user notification channels because the existing listener uses a single static channel, while notification channels are dynamic (subscribe/unsubscribe per user).

Add a new function `start_notification_listener`:

```python
async def start_notification_listener(redis_pool: Any, app_state: Any) -> None:
    """Start dedicated pub/sub listener for per-user notification channels.

    Unlike the cache invalidation listener (static channel), this listener
    dynamically subscribes/unsubscribes to per-user channels as WebSocket
    clients connect and disconnect.

    The pubsub object is stored on app_state.notify_pubsub so the WebSocket
    endpoint can call subscribe/unsubscribe on it.
    """
    import redis.asyncio as redis

    client = redis.Redis(connection_pool=redis_pool)

    try:
        pubsub = client.pubsub()
        app_state.notify_pubsub = pubsub

        logger.info("notification_listener_started")

        async for message in pubsub.listen():
            if message["type"] == "message":
                await _handle_notification(message, app_state)

    except asyncio.CancelledError:
        logger.info("notification_listener_cancelled")
        raise
    except Exception as e:
        logger.error("notification_listener_error", error=str(e))
        raise
    finally:
        try:
            await client.aclose()
        except Exception as e:
            logger.debug("notification_cleanup_error", error=str(e))
```

Add the `_handle_notification` handler:

```python
async def _handle_notification(message: dict, app_state: Any) -> None:
    """Handle notification pub/sub message and forward to WebSocket clients.

    Extracts user_id from channel name and sends payload via ConnectionManager.
    """
    try:
        channel = message.get("channel", b"")
        if isinstance(channel, bytes):
            channel = channel.decode("utf-8")

        # Extract user_id from channel: "memora:notify:{user_id}"
        if not channel.startswith("memora:notify:"):
            return

        user_id = channel[len("memora:notify:"):]

        data = message.get("data", b"")
        if isinstance(data, bytes):
            data = data.decode("utf-8")

        # Forward raw JSON to all user's WebSocket connections
        ws_manager = getattr(app_state, "ws_manager", None)
        if ws_manager:
            sent = await ws_manager.send_to_user(user_id, data)
            logger.info("notification_forwarded", user_id=user_id, sent_count=sent)
        else:
            logger.warning("ws_manager_not_available")

    except Exception as e:
        logger.error("notification_handler_error", error=str(e))
```
