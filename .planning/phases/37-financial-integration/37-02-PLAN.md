```python
def on_update(self):
    if not self.has_value_changed("status"):
        return
    if self.status == "Completed":
        if self.allocation_type == "Allocate":
            self._apply_allocation()
            if self.sale_model == "Prepaid":
                self._create_prepaid_invoice()
        elif self.allocation_type == "Return":
            self._apply_return()
            if self.sale_model == "Prepaid":
                self._create_prepaid_credit_note()
            # FIN-06: Consignment returns require NO financial action
        self._update_batch_counters()
```

Create `memora_admin/tasks/consignment_billing.py` with function `generate_monthly_invoices()`:

1. Calculate the previous month window:
   - `today = nowdate()`
   - `prev_month_start = get_first_day(add_months(today, -1))` -- e.g., "2026-01-01"
   - `prev_month_end = get_last_day(add_months(today, -1))` -- e.g., "2026-01-31"

2. Query redeemed consignment cards not yet invoiced:
   ```sql
   SELECT c.name, c.batch, c.library, c.redeemed_at,
          b.face_value, b.batch_name
   FROM `tabMemora Voucher Card` c
   JOIN `tabMemora Voucher Batch` b ON c.batch = b.name
   WHERE c.status = 'Redeemed'
     AND c.sale_model = 'Consignment'
     AND (c.sales_invoice IS NULL OR c.sales_invoice = '')
     AND c.redeemed_at >= %s
     AND c.redeemed_at <= %s
   ORDER BY c.library, c.batch
   ```
   Pass `(prev_month_start, prev_month_end + " 23:59:59")` as params (redeemed_at is datetime, not date).

3. If no cards found, return early (log info message "No consignment cards to invoice").

4. Group cards by `library` using `itertools.groupby` (data is already sorted by library from ORDER BY).

5. For each library group:
   - Sub-group by `batch` (data sorted by batch within library)
   - For each batch sub-group:
     - Resolve commission: `resolve_commission(batch_name, library)`
     - Calculate amounts: `calculate_commission(face_value, card_count, commission_type, commission_value)`
     - Build invoice item dict: `description=f"Consignment - Batch {batch_name} ({month_label})"`, `qty=card_count`, `rate=result["net_per_card"]`
   - Create ONE invoice per library (multiple items if multiple batches) via `create_voucher_invoice()`:
     - `customer=library`
     - `items=batch_item_list` (one item per batch in the library)
     - `remarks=f"Monthly consignment billing {month_label} | {total_cards} cards from {batch_count} batch(es)"`
     - `posting_date=get_first_day(today)` -- invoice dated on the 1st of current month (the billing date)
   - After invoice creation, bulk UPDATE all cards in this library group to set `sales_invoice = invoice_name`
   - `frappe.db.commit()` after each library to prevent one library's failure from rolling back another's

6. Wrap each library's processing in try/except: on failure, `frappe.db.rollback()` then `frappe.log_error(title=f"Consignment billing failed for {library}")`, then continue to next library.

7. Build `month_label` as `f"{prev_month_start} to {prev_month_end}"` for readability in remarks.

Import: `frappe`, `frappe.utils` (nowdate, add_months, get_first_day, get_last_day), `itertools.groupby`, `operator.itemgetter`, and the commission/invoice service functions.
