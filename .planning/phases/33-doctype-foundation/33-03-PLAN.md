    - Fields (SEC-03 -- all required audit fields):
      - `player`: Link to "Memora Player Profile", required, in_list_view 1, in_standard_filter 1, label "Player"
      - `pin_masked`: Data, required, in_list_view 1, label "PIN (Masked)" -- last 4 digits only, e.g., "****5678"
      - `card`: Link to "Memora Voucher Card", in_list_view 1, label "Card" -- null for invalid PIN attempts
      - `library`: Link to "Customer", in_standard_filter 1, label "Library" -- from card's allocation
      - `column_break_1`: Column Break
      - `batch`: Link to "Memora Voucher Batch", in_standard_filter 1, label "Batch"
      - `requested_grant`: Link to "Memora Product Grant", label "Requested Grant"
      - `status`: Select, options "Success\nInvalid PIN\nAlready Redeemed\nExpired\nVoid\nBatch Inactive\nSeason Inactive\nAll Grants Owned\nGrant Not In Batch\nAlready Owned\nRate Limited\nNot Allocated\nError", required, in_list_view 1, in_standard_filter 1, label "Status"
      - `section_details`: Section Break, label "Details"
      - `failure_reason`: Data, label "Failure Reason"
      - `ip_address`: Data, label "IP Address"
      - `timestamp`: Datetime, required, in_list_view 1, label "Timestamp"
    - **Permissions (CRITICAL -- immutable log):**
      ```json
      [
        {
          "create": 1,
          "email": 1,
          "export": 1,
          "print": 1,

    def _setup_voucher_schema():
    	"""Set up voucher-related schema extensions. Idempotent."""
    	from memora_admin.memora_admin.custom.customer_fields import add_customer_voucher_fields

    	add_customer_voucher_fields()
    	print("[after_migrate] Customer voucher fields ensured")

    	_ensure_voucher_card_indexes()


    def _ensure_voucher_card_indexes():
    	"""Create composite index on Voucher Card (batch, status) for allocation queries.

    	This index optimizes: "get N Available cards from batch X" (used by Phase 35 allocation).
    	Frappe's search_index creates simple indexes; composite indexes need manual creation.
    	"""
    	# Skip if table doesn't exist yet (fresh install before bench migrate)
    	tables = frappe.db.get_tables()
    	if "tabMemora Voucher Card" not in tables:
    		return

    	existing = frappe.db.sql("""
    		SELECT DISTINCT INDEX_NAME FROM INFORMATION_SCHEMA.STATISTICS
    		WHERE TABLE_SCHEMA = DATABASE()
    		AND TABLE_NAME = 'tabMemora Voucher Card'
    		AND INDEX_NAME = 'idx_batch_status'
    	""")

    	if not existing:
    		frappe.db.sql_ddl("""
    			ALTER TABLE `tabMemora Voucher Card`
    			ADD INDEX idx_batch_status (batch, status)
    		""")
    		print("[after_migrate] Created INDEX idx_batch_status on tabMemora Voucher Card")
    ```
