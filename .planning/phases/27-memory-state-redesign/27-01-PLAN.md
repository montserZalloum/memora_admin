    The definitive implementation approach (from RESEARCH.md, verified working):
    ```python
    def _ensure_uuid_polyfill_functions():
        """Create UUID_TO_BIN and BIN_TO_UUID polyfill stored functions.
        MariaDB 10.6 lacks these (MySQL 8.0 only). Uses UNHEX/HEX under the hood."""
        result = frappe.db.sql("""
            SELECT ROUTINE_NAME FROM INFORMATION_SCHEMA.ROUTINES
            WHERE ROUTINE_SCHEMA = DATABASE()
            AND ROUTINE_NAME = 'UUID_TO_BIN'
        """)
        if result:
            return  # Already exists

        # UUID_TO_BIN: single-expression function, works directly with sql_ddl
        frappe.db.sql_ddl("DROP FUNCTION IF EXISTS UUID_TO_BIN")
        frappe.db.sql_ddl("""
            CREATE FUNCTION UUID_TO_BIN(uuid CHAR(36))
            RETURNS BINARY(16) DETERMINISTIC NO SQL
            RETURN UNHEX(REPLACE(uuid, '-', ''))
        """)

        # BIN_TO_UUID: multi-statement function with BEGIN/END block.
        # frappe.db.sql_ddl() handles this correctly because Frappe's MariaDB
        # connector sends the full statement to the server as a single command.
        # The BEGIN/END block does NOT require DELIMITER changes when sent via
        # a programmatic client (DELIMITER is only needed in the mysql CLI).
        frappe.db.sql_ddl("DROP FUNCTION IF EXISTS BIN_TO_UUID")
        frappe.db.sql_ddl("""
            CREATE FUNCTION BIN_TO_UUID(b BINARY(16))
            RETURNS CHAR(36) DETERMINISTIC NO SQL
            BEGIN
                DECLARE hexStr CHAR(32);
                SET hexStr = HEX(b);
                RETURN LOWER(CONCAT(
                    SUBSTR(hexStr, 1, 8), '-',
                    SUBSTR(hexStr, 9, 4), '-',
                    SUBSTR(hexStr, 13, 4), '-',
                    SUBSTR(hexStr, 17, 4), '-',
                    SUBSTR(hexStr, 21)
                ));
            END
        """)
    ```

    **Key technical note:** `frappe.db.sql_ddl()` sends the SQL as a single statement via the MariaDB programmatic connector (PyMySQL/mysqlclient). The `DELIMITER` command is a mysql CLI feature only -- programmatic clients send one statement at a time and handle `BEGIN/END` blocks natively. This is the same mechanism used by all ORMs and migration tools. No special delimiter handling is needed.
