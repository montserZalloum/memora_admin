2. Create `storage/base.py` with abstract StorageBackend:
   ```python
   from abc import ABC, abstractmethod

   class StorageBackend(ABC):
       @abstractmethod
       def upload(self, key: str, content: bytes, content_type: str = "application/json") -> str:
           """Upload content, return public URL."""
           pass

       @abstractmethod
       def delete(self, key: str) -> bool:
           """Delete file, return success."""
           pass

       @abstractmethod
       def exists(self, key: str) -> bool:
           """Check if file exists."""
           pass
   ```

3. Create `storage/local.py` with LocalStorageBackend:
   - `__init__(self, base_path: str, base_url: str = "/files/cdn")`:
     - Store base_path as Path object
     - Create directory if not exists with `mkdir(parents=True, exist_ok=True)`
   - `upload(self, key, content, content_type)`:
     - Build target path: `self.base_path / key`
     - Create parent directories if needed
     - Use atomic write pattern:
       - Create temp file with `tempfile.mkstemp(dir=target_path.parent)`
       - Write content, flush, fsync
       - Use `os.replace(temp_path, target_path)` for atomic swap
     - Return URL: `f"{self.base_url}/{key}"`
     - Handle exceptions: cleanup temp file on error
   - `delete(self, key)`: unlink if exists, return success
   - `exists(self, key)`: return path.exists()

4. Create `storage/__init__.py`:
   - Import StorageBackend, LocalStorageBackend
   - Create `get_storage_backend() -> StorageBackend`:
     - Get base path from frappe.get_site_path("public", "files", "cdn")
     - Return LocalStorageBackend instance
     - (R2 backend can be added later based on site config)

   Per CONTEXT.md atomic swap and retry requirements:

   a) Get storage backend via `get_storage_backend()`

   b) Create temp prefix: `_temp_{timestamp}/`

   c) Flatten nested file structure:
      - `_flatten_files(files)` helper
      - Recursively collects all files from nested children

   d) Phase 1 - Upload to temp location:
      - For each file in flattened list:
        - Build temp_key: `temp_prefix + filename`
        - Encode content: `content.encode("utf-8")`
        - Attempt upload with retry loop (max_retries times)
        - On failure after all retries:
          - Cleanup uploaded temp files
          - Log error with `frappe.log_error`
          - Return False
        - Exponential backoff between retries: `time.sleep(2 ** attempt)`

   e) Phase 2 - Atomic swap:
      - For each (temp_key, final_key) pair:
        - For local storage: files already in place, just rename
        - Read content from temp, write to final location
        - Handle errors gracefully

   f) Phase 3 - Cleanup:
      - Delete temp files (best effort, don't fail if cleanup fails)

   g) Return True on success

2. Create `_flatten_files(files: list[dict]) -> list[dict]`:
   - For each file dict, add to result
   - If file has "children" key with content, recursively flatten children
   - Return flat list of {filename, content} dicts
