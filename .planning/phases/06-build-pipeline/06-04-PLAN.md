  <action>
Create build worker for processing pending builds:

1. Create `memora_admin/memora_admin/tasks/` directory if not exists
2. Create `tasks/__init__.py` (empty or with module docstring)

3. Create `tasks/build_worker.py`:

   a) `process_pending_builds()` - main scheduler entry point:
      - Get all pending builds: `frappe.get_all("Memora Build Queue", filters={"status": "Pending"}, ...)`
      - Order by creation asc (oldest first)
      - For each build, call `_process_single_build(build)` in try/except
      - On exception, call `_mark_build_failed(build.name, str(e))`

   b) `_process_single_build(build: dict)`:
      - Get build doc: `frappe.get_doc("Memora Build Queue", build.name)`
      - Set status to "Processing", started_at to now, save
      - Import and call `generate_subject_json(build.target_name)`
      - Import and call `publish_to_cdn(files, max_retries=3)`
      - If upload succeeds:
        - Set status to "Completed"
        - Set files_generated count
        - Call `_notify_cache_invalidation(build.target_name)`
        - Call `_send_notification(build.target_name, success=True)`
      - If upload fails:
        - Call `_requeue_build(build_doc)` with retry logic
      - Finally: set completed_at, calculate duration_sec, save

   c) `_notify_cache_invalidation(subject_id: str)`:
      - Publish to Redis channel `memora:cache:invalidate`
      - Message: JSON with `{"type": "hierarchy", "subject_id": ..., "timestamp": ...}`
      - Use `frappe.cache.publish(channel, message)`

   d) `_send_notification(subject_id: str, success: bool, error: str = None)`:
      - Build message based on success/failure
      - Use `frappe.publish_realtime(event="build_complete", message=..., after_commit=True)`

   e) `_mark_build_failed(build_name: str, error: str)`:
      - Load build doc, set status to "Failed", error_message to error, save

   f) `_requeue_build(build_doc)`:
      - If retry count (can track via error_message or new field) < 3:
        - Reset status to "Pending" for retry
      - Else: mark as Failed

4. Update `hooks.py` with scheduler_events:
   ```python
   scheduler_events = {
       "cron": {
           "*/2 * * * *": [
               "memora_admin.tasks.build_worker.process_pending_builds"
           ]
       }
   }
   ```
  </action>

    - Frappe realtime notifications for success/failure
    - hooks.py has scheduler_events cron every 2 minutes
  </done>

  <action>
Create FastAPI pub/sub listener:

1. Create `fastapi_app/core/pubsub.py`:

   a) Define constant: `INVALIDATION_CHANNEL = "memora:cache:invalidate"`

   b) Create `async def start_pubsub_listener(redis_pool, app_state)`:
      - Create Redis client from pool
      - Create pubsub object: `client.pubsub()`
      - Subscribe to INVALIDATION_CHANNEL
      - Log subscription with structlog
      - Async for loop over `pubsub.listen()`:
        - If message type is "message", call `_handle_invalidation(message["data"], app_state)`
      - Handle CancelledError for clean shutdown
      - Finally: unsubscribe and close client

   c) Create `async def _handle_invalidation(data, app_state)`:
      - Decode data if bytes
      - Parse JSON payload
      - If type is "hierarchy" and subject_id present:
        - Get hierarchy_service from app_state
        - Call `await hierarchy_service.invalidate(subject_id)`
        - Log invalidation with structlog
      - Handle exceptions gracefully (log error, don't crash listener)

2. Update `fastapi_app/main.py` lifespan:
   - Import `start_pubsub_listener` from `fastapi_app.core.pubsub`
   - Import `asyncio`
   - After Redis pool setup, before yield:
     - Create HierarchyService instance (need to import and FrappeClient)
     - Store hierarchy_service in app.state
     - Create background task: `asyncio.create_task(start_pubsub_listener(pool, app.state))`
     - Store task in app.state.pubsub_task
   - After yield (cleanup):
     - Cancel pubsub_task
     - Try await with CancelledError catch

Note: HierarchyService requires FrappeClient. Create FrappeClient instance in lifespan and pass to HierarchyService. Both stored in app.state.
