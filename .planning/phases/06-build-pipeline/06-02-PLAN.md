<task type="auto">
  <name>Task 2: Create JSON generator for hierarchy, lesson content, and bitmap</name>
  <files>
    memora_admin/memora_admin/services/build/generator.py

  <action>
Create `memora_admin/memora_admin/services/build/generator.py` with JSON generation logic:

1. Define `SCHEMA_VERSION = 1` constant

2. Create `generate_subject_json(subject_id: str) -> list[dict]`:
   - Returns list of file dicts: `{"filename": str, "content": str, "subject_id": str | None}`
   - Get subject doc with `frappe.get_doc("Memora Subject", subject_id)`
   - Generate files at each level (see below)

3. Per CONTEXT.md and REQUIREMENTS.md, generate separate files:

   a) `_subjects.json` (subject level):
      ```json
      {
        "schema_version": 1,
        "subjects": [{
          "subject_id": "...",
          "title": "...",
          "image": "...",  // relative path
          "is_linear": true/false,
          "track_ids": ["TRK-001", ...]
        }]
      }
      ```

   b) `track_{id}.json` (one per track):
      ```json
      {
        "schema_version": 1,
        "track_id": "...",
        "title": "...",
        "image": "...",
        "is_linear": true/false,
        "unit_ids": ["UNIT-001", ...]
      }
      ```

   c) `unit_{id}.json` (one per unit - BUILD-04 compliant):
      Per BUILD-04: "Generate unit content JSON with topics and lesson metadata"
      ```json
      {
        "schema_version": 1,
        "unit_id": "...",
        "title": "...",
        "is_linear": true/false,
        "is_free": true/false,
        "topics": [
          {
            "topic_id": "...",
            "title": "...",
            "is_linear": true/false,
            "is_free": true/false,
            "lessons": [
              {"lesson_id": "...", "title": "...", "bit_index": N}
            ]
          }
        ]
      }
      ```
      Note: unit_{id}.json now includes full topic and lesson metadata inline (not just IDs).

   d) `topic_{id}.json` (one per topic - navigation metadata):
      ```json
      {
        "schema_version": 1,
        "topic_id": "...",
        "title": "...",
        "is_linear": true/false,
        "is_free": true/false,
        "lesson_ids": ["LES-001", "LES-002"]
      }
      ```

   e) `lesson_{id}.json` (one per lesson - BUILD-05 compliant):
      Per BUILD-05: "Generate lesson JSON with stages array and stage configurations"
      ```json
      {
        "schema_version": 1,
        "lesson_id": "...",
        "title": "...",
        "base_xp": 10,
        "max_hearts": 3,
        "bit_index": N,
        "is_reviewable": true/false,
        "stages": [
          {
            "stage_id": "...",
            "stage_type": "...",
            "is_skippable": true/false,
            "config": {...}  // parsed from config_json
          }
        ]
      }
      ```
      Note: config_json is stored as JSON string in DB, parse it for output.

   f) `{subject_id}_b.json` (bitmap metadata):
      ```json
      {
        "schema_version": 1,
        "subject_id": "...",
        "bit_range": N,
        "excluded_bits": [1, 5, ...],
        "generated_at": "timestamp"
      }
      ```

4. Create helper functions:
   - `_generate_track_json(track)` - returns dict with filename, content, and children list
   - `_generate_unit_json(unit)` - generates unit_{id}.json with full topic/lesson content
   - `_generate_topic_json(topic)` - generates topic_{id}.json with lesson_ids
   - `_generate_lesson_json(lesson_doc)` - generates lesson_{id}.json with stages array
   - `_generate_bitmap_json(subject_id)` - calculates bit_range and excluded_bits
   - `_relative_path(url)` - strips domain prefix, returns path only
   - `_parse_stage_config(config_json_str)` - safely parse stage config JSON

5. For lesson stages:
   - Get lesson doc with `frappe.get_doc("Memora Lesson", lesson_name)` to access child table
   - Access stages via `lesson_doc.stages` (list of child rows)
   - Each stage has: stage_id, stage_type (Link), is_skippable, config_json (JSON string)
   - Parse config_json with json.loads(), handle malformed JSON gracefully

6. Use `frappe.get_all()` with filters and order_by for child entities
7. Use `json.dumps(data, ensure_ascii=False, indent=2)` for formatted JSON
8. Handle malformed data per CONTEXT.md: skip with warning, log, continue build
