<task type="auto">
  <name>Task 2: Create JSON generator for hierarchy and bitmap</name>
  <files>
    memora_admin/memora_admin/services/build/generator.py

  <action>
Create `memora_admin/memora_admin/services/build/generator.py` with JSON generation logic:

1. Define `SCHEMA_VERSION = 1` constant

2. Create `generate_subject_json(subject_id: str) -> list[dict]`:
   - Returns list of file dicts: `{"filename": str, "content": str, "subject_id": str | None}`
   - Get subject doc with `frappe.get_doc("Memora Subject", subject_id)`
   - Generate files at each level:

3. Per CONTEXT.md JSON structure, generate separate files:

   a) `_subjects.json` (subject level):
      ```json
      {
        "schema_version": 1,
        "subjects": [{
          "subject_id": "...",
          "title": "...",
          "image": "...",  // relative path
          "is_linear": true/false,
          "track_ids": ["TRK-001", ...]
        }]
      }
      ```

   b) `track_{id}.json` (one per track):
      ```json
      {
        "schema_version": 1,
        "track_id": "...",
        "title": "...",
        "image": "...",
        "is_linear": true/false,
        "unit_ids": ["UNIT-001", ...]
      }
      ```

   c) `unit_{id}.json` (one per unit):
      ```json
      {
        "schema_version": 1,
        "unit_id": "...",
        "title": "...",
        "is_linear": true/false,
        "is_free": true/false,
        "topic_ids": ["TOPIC-001", ...]
      }
      ```

   d) `topic_{id}.json` (one per topic):
      ```json
      {
        "schema_version": 1,
        "topic_id": "...",
        "title": "...",
        "is_linear": true/false,
        "is_free": true/false,
        "lessons": [
          {"lesson_id": "...", "title": "...", "url": "/lessons/..."}
        ]
      }
      ```

   e) `{subject_id}_b.json` (bitmap metadata):
      ```json
      {
        "schema_version": 1,
        "subject_id": "...",
        "bit_range": N,
        "excluded_bits": [1, 5, ...],
        "generated_at": "timestamp"
      }
      ```

4. Create helper functions:
   - `_generate_track_json(track)` - returns dict with filename, content, and children list
   - `_generate_unit_json(unit)` - similar pattern
   - `_generate_topic_json(topic)` - similar pattern
   - `_generate_bitmap_json(subject_id)` - calculates bit_range and excluded_bits
   - `_relative_path(url)` - strips domain prefix, returns path only

5. Use `frappe.get_all()` with filters and order_by for child entities
6. Use `json.dumps(data, ensure_ascii=False, indent=2)` for formatted JSON
7. Handle malformed data per CONTEXT.md: skip with warning, log, continue build
