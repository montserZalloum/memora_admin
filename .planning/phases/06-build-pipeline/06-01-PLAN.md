2. Create `on_content_updated(doc, method)` handler:

     - Memora Subject: `doc.name`
     - Memora Track: `doc.subject`
     - Memora Unit: get track, then subject via `frappe.get_cached_value`
     - Memora Topic: get unit, track, then subject via chained lookups
     - Memora Lesson: `doc.subject` (direct link)
   - If subject_id not found, log error and return
   - Use Redis SET NX EX pattern for debounce: `cache.set(debounce_key, timestamp, nx=True, ex=DEBOUNCE_SECONDS)`

   - Otherwise create Build Queue entry with:
     - target_type: "Memora Subject"
     - target_name: subject_id
     - trigger_reason: "content_update"
     - triggered_by: frappe.session.user
     - status: "Pending"
   - Use `insert(ignore_permissions=True)`

3. Create helper `_get_subject_id(doc)` to extract subject from any content DocType

4. Update `memora_admin/hooks.py`:
   - Add doc_events for Memora Subject, Track, Unit, Topic, Lesson
   - All use `on_update` hook pointing to `memora_admin.events.build_trigger.on_content_updated`
   - Follow existing pattern from Season/Subscription events

Follow access_sync.py patterns for logging and error handling.
