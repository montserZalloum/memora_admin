**1. `_log_attempt()` helper** (not whitelisted, internal only):
- Creates a `Memora Voucher Redemption Log` entry with `insert(ignore_permissions=True)`
- Parameters: `player_id, pin_masked, card, library, batch, requested_grant, status, failure_reason, ip_address`
- `pin_masked` should be formatted as `"****{last4}"` where last4 is the last 4 chars of the pin_hmac
- `timestamp` = `frappe.utils.now()`
- The `status` field uses: "Success" or "Failed"
- The `failure_reason` field stores the error code string (INVALID_PIN, ALREADY_REDEEMED, etc.) for failed attempts, empty string for success

**2. `preview_voucher(pin_hmac, player_id)` whitelisted method:**
- Decorated with `@frappe.whitelist(allow_guest=False)`
- Returns a dict -- either `{"error": "ERROR_CODE"}` or `{"face_value": "...", "grants": [...]}`
- Validation chain (in order):
  1. Look up card by `pin_hmac` using `frappe.db.sql("SELECT name, status, batch FROM tabMemora Voucher Card WHERE pin_hmac = %s LIMIT 1", ...)`. No FOR UPDATE needed (read-only).
  2. If no card found: return `{"error": "INVALID_PIN"}`
  3. Timing-safe verification: `hmac_module.compare_digest(card.pin_hmac, pin_hmac)` -- import `hmac as hmac_module` at top. Note: Since we found the card by WHERE clause, this comparison is technically redundant but satisfies REDEEM-09. If it fails, return `{"error": "INVALID_PIN"}`.
  4. Card status validation: Map statuses to error codes: Available->"NOT_ALLOCATED", Redeemed->"ALREADY_REDEEMED", Void->"VOID", Expired->"EXPIRED". If status is not "Allocated", return the mapped error or "INVALID_PIN" for unknown.
  5. Batch validation: `frappe.db.get_value("Memora Voucher Batch", card.batch, "status")`. If not "Active", return `{"error": "BATCH_INACTIVE"}`.
  6. Season validation: Get the batch's season link. Check if season is published and not ended. Use `frappe.db.get_value("Memora Season", season_name, ["is_published", "end_date"])`. If season is not published or `end_date < today`, return `{"error": "SEASON_INACTIVE"}`. If the batch has no season linked, skip this check (some batches may not be season-specific).
  7. Build available grants: Load batch doc with `frappe.get_doc("Memora Voucher Batch", card.batch)`. For each `batch_grant` in `batch.batch_grants`, call `get_grant_keys(bg.product_grant)` (import from `memora_admin.memora_admin.api.products`). Check if player owns ALL keys via `frappe.db.exists("Memora Player Subscription", {"player": player_id, "access_key": key})`. If not all owned, add to available list.
  8. For display name: Use `frappe.db.get_value("Memora Product Grant", bg.product_grant, "grant_label")` with fallback to `bg.product_grant` (same pattern as existing `generate_cards_job` on line 103).
  9. If no available grants: return `{"error": "ALL_GRANTS_OWNED"}`
  10. Return: `{"face_value": str(batch.face_value or "0"), "grants": [{"grant_id": bg.product_grant, "name": display_name}, ...]}`

**3. `redeem_voucher(pin_hmac, player_id, product_grant_id, ip_address)` whitelisted method:**
- Decorated with `@frappe.whitelist(allow_guest=False)`
- Returns a dict -- either `{"error": "ERROR_CODE"}` or `{"status": "success", "transaction_id": "..."}`
- `ip_address` defaults to empty string
- Validation chain with SELECT FOR UPDATE:
  1. Lock card row: `frappe.db.sql("SELECT name, status, batch, pin_hmac FROM tabMemora Voucher Card WHERE pin_hmac = %s FOR UPDATE", ...)` -- this acquires row-level lock
  2. If no card: log attempt with `_log_attempt(player_id, pin_hmac[-4:], None, None, None, product_grant_id, "Failed", "INVALID_PIN", ip_address)`, return `{"error": "INVALID_PIN"}`
  3. Timing-safe HMAC comparison: `hmac_module.compare_digest(card.pin_hmac, pin_hmac)`. If fails, log + return INVALID_PIN.
  4. Card status must be "Allocated". Map other statuses: Available->"NOT_ALLOCATED", Redeemed->"ALREADY_REDEEMED", Void->"VOID", Expired->"EXPIRED". Log + return error.
  5. Batch status must be "Active". If not, log + return `{"error": "BATCH_INACTIVE"}`.
  6. Season validation (same as preview): If batch has season and season is inactive, log + return `{"error": "SEASON_INACTIVE"}`.
  7. Validate grant belongs to batch: `frappe.get_all("Memora Voucher Batch Grant", filters={"parent": card.batch}, pluck="product_grant")`. If `product_grant_id` not in list, log + return `{"error": "GRANT_NOT_IN_BATCH"}`.
  8. Check ALREADY_OWNED (does NOT consume card per user decision): Call `get_grant_keys(product_grant_id)`, check all keys owned. If all owned, log + return `{"error": "ALREADY_OWNED"}`.
  9. Mark card as Redeemed: `frappe.db.set_value("Memora Voucher Card", card.name, {"status": "Redeemed", "redeemed_by": player_id, "redeemed_at": frappe.utils.now(), "redeemed_grant": product_grant_id})`
  10. Get card's library for audit log: `library = frappe.db.get_value("Memora Voucher Card", card.name, "library")`
  11. Get face_value from batch: `face_value = frappe.db.get_value("Memora Voucher Batch", card.batch, "face_value") or 0`
  12. Create Subscription Transaction with TWO-STEP SAVE (CRITICAL):
      ```python
      trx = frappe.get_doc({
          "doctype": "Memora Subscription Transaction",
          "player": player_id,
          "payment_method": "Voucher",
          "status": "Pending Approval",  # MUST start here
          "related_grant": product_grant_id,
          "amount_paid": face_value,
          "transaction_id": card.name,
      })
      trx.insert(ignore_permissions=True)
      # Step 2: change status and save -- triggers on_update -> _handle_approval()
      trx.status = "Completed"
      trx.save(ignore_permissions=True)
      ```
  13. Link transaction back to card: `frappe.db.set_value("Memora Voucher Card", card.name, "subscription_transaction", trx.name)`
  14. Log success: `_log_attempt(player_id, pin_hmac[-4:], card.name, library, card.batch, product_grant_id, "Success", "", ip_address)`
  15. Update batch redeemed_count: `redeemed = frappe.db.count("Memora Voucher Card", {"batch": card.batch, "status": "Redeemed"})` then `frappe.db.set_value("Memora Voucher Batch", card.batch, "redeemed_count", redeemed, update_modified=True)`
  16. `frappe.db.commit()`
  17. Return `{"status": "success", "transaction_id": trx.name}`
