**HMAC computation method:**
```python
def _compute_hmac(self, pin: str) -> str:
    return hmac_module.new(
        self.hmac_secret.encode("utf-8"),
        pin.encode("utf-8"),
        hashlib.sha256,
    ).hexdigest()
```

**Rate limiting with Lua scripts** (failed-attempt-only):

Two Lua scripts as module-level constants:
- `CHECK_LIMIT_SCRIPT`: GET key, if count >= limit return TTL, else return 0
- `INCREMENT_SCRIPT`: INCR key, if count == 1 then EXPIRE with window, return count

Constants: `PLAYER_LIMIT = 5`, `IP_LIMIT = 20`, `WINDOW_SECONDS = 3600`

Methods:
- `async def check_rate_limit(self, player_id: str, ip: str) -> int | None`: Check both player and IP keys. Returns retry_after seconds (int > 0) if limited, else None. Uses keys `memora:voucher_fail:player:{player_id}` and `memora:voucher_fail:ip:{ip}`.
- `async def record_failure(self, player_id: str, ip: str) -> None`: Increment both player and IP counters (called only on failed attempts).
- `async def preview(self, pin: str, player_id: str) -> dict`: Compute HMAC, call `self.frappe.call("memora_admin.api.voucher.preview_voucher", {"pin_hmac": pin_hmac, "player_id": player_id})`. Return the result dict directly.
- `async def redeem(self, pin: str, player_id: str, grant_id: str, ip: str) -> dict`: Compute HMAC, call `self.frappe.call("memora_admin.api.voucher.redeem_voucher", {"pin_hmac": pin_hmac, "player_id": player_id, "product_grant_id": grant_id, "ip_address": ip})`. Return the result dict directly.

def _get_client_ip(request: Request) -> str:
    forwarded = request.headers.get("X-Forwarded-For")
    if forwarded:
        return forwarded.split(",")[0].strip()
    return request.client.host if request.client else "unknown"

**POST /voucher/preview endpoint:**
- Parameters: `request: Request`, `body: VoucherPreviewRequest`, `user: CurrentUser`, `voucher_service: VoucherServiceDep`
- NOT rate limited (per user decision -- preview is forgiving for young students)
- Call `voucher_service.preview(body.pin, user.sub)`
- If result has "error" key, return `JSONResponse(status_code=ERROR_STATUS_MAP.get(error, 400), content=result)`
- On success, return result directly (200 OK)
- Wrap in try/except for `redis.RedisError` (503) and generic Exception (500 with logging)

**POST /voucher/redeem endpoint:**
- Parameters: `request: Request`, `body: VoucherRedeemRequest`, `user: CurrentUser`, `voucher_service: VoucherServiceDep`
- Rate limiting flow:
  1. Get client IP via `_get_client_ip(request)`
  2. Check rate limit BEFORE operation: `retry_after = await voucher_service.check_rate_limit(user.sub, client_ip)`
  3. If `retry_after is not None` (and > 0), return 429: `JSONResponse(status_code=429, content={"error": "RATE_LIMITED", "retry_after": retry_after})`
  4. Call `voucher_service.redeem(body.pin, user.sub, body.grant_id, client_ip)`
  5. If result has "error" key AND the error is in `FAILURE_ERRORS`: call `await voucher_service.record_failure(user.sub, client_ip)`. Then return JSONResponse with mapped status code.
  6. If result has "error" but NOT in FAILURE_ERRORS (shouldn't happen, but defensive): return error without recording failure.
  7. On success, return result directly (200 OK)
  8. Wrap in try/except for `redis.RedisError` (503) and generic Exception (500 with logging)

Import `FAILURE_ERRORS` from `fastapi_app.services.voucher`.
