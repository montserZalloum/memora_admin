## End-to-End Flows

All 4 critical user flows verified:

### Flow 1: Player Login → Access Content ✓
```
POST /auth/login → JWT issued → GET /progress/{subject} → Gate 1 (season) →
Gate 2 (access) → Return progress with unlock states
```

### Flow 2: Complete Lesson → Earn Rewards ✓
```
POST /progress/complete → Gate validation → SETBIT bitmap → Mark dirty →
Award XP (HINCRBY) → Update streak (Lua) → Mark wallet dirty → Return response
```

### Flow 3: Content Update → Build → Cache Invalidation ✓
```
Save Subject in Frappe → doc_events hook → Build Queue → build_worker →
Generate JSON → Upload CDN → publish(memora:cache:invalidate) →
FastAPI subscriber → Clear hierarchy cache
```

### Flow 4: Background Sync ✓
```
Scheduler (1 min) → sync_dirty_progress → SMEMBERS → bitmap.hex() →
Upsert Structure Progress → SREM after success
Scheduler (1 min) → sync_dirty_wallets → SMEMBERS → HGETALL →
Update Player Wallet → SREM after success
```
