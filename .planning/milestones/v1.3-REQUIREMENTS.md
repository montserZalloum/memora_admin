## v1.3 Requirements

Requirements for milestone v1.3: Leaderboard Profiles & Admin Device Management.

### Profile Display Names

- [x] **PROF-01**: Leaderboard responses include display_name from Memora Player Profile — v1.3
- [x] **PROF-02**: Leaderboard responses include avatar from Memora Player Profile — v1.3
- [x] **PROF-03**: ProfileService caches profiles in Redis hash (1hr TTL) — v1.3
- [x] **PROF-04**: Batch profile lookup via Redis pipeline (<25ms for 100 entries) — v1.3
- [x] **PROF-05**: Profile cache invalidated on Memora Player Profile update — v1.3

### Admin Device Management

- [x] **ADMDEV-01**: Admin can view player's registered devices in Frappe Desk — v1.3
- [x] **ADMDEV-02**: Device data synced from Redis to Frappe child table — v1.3
- [x] **ADMDEV-03**: Admin can remove a device (clears from Redis) — v1.3

### JWT Simplification

- [x] **JWT-01**: Add plan_id to access token (from Memora Player Profile) — v1.3
- [x] **JWT-02**: Remove timezone from access token (hardcode Asia/Amman) — v1.3
- [x] **JWT-03**: Remove role from access token (all API users are players) — v1.3

### Stage Content Editor

- [x] **STAGE-EDIT-01**: Edit Content button opens type-specific dialogs for lesson stages — v1.3

### Progress API Optimization (added during milestone)

- [x] **PROG-OPT-01**: Progress stats cached in Redis hash with O(1) updates — v1.3
- [x] **PROG-OPT-02**: SSE streaming endpoint for progressive progress delivery — v1.3
