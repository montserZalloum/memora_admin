## Milestone Summary

**Key Decisions:**
- Individual Redis keys with pipeline MGET for profile cache (Redis <7.4 compatibility)
- plan_id in JWT token, timezone/role removed (hardcoded)
- frm.add_child + refresh_field for child table updates (avoids Frappe reload_doc loops)
- sse-starlette for SSE support (subject summary first, then track events)
- Pipeline GETBIT for per-lesson status (not full bitmap load)
- Lua session_complete script for ~4 Redis round-trips in hot path
- FSRS processing in background task (not hot path) to keep completion <10ms
- Hearts bonus XP not applied to replays

**Issues Resolved:**
- Frappe form infinite loop (reload_doc triggers getdoc which triggers refresh)
- Redis namespace mismatch in device_sync.py (frappe.cache vs get_fastapi_redis)
- ISO 8601 datetime conversion for Frappe child table fields
- Missing Redis cache population for plan subjects (event handler existed but never seeded)

**Issues Deferred:**
- No monitoring for pub/sub listener failures
- No circuit breaker on FrappeClient API calls
- No exposed metrics for cache hit rates
- Single Redis instance is SPOF

**Technical Debt Incurred:**
- Phase 16 had 5 post-feat fix commits (Frappe form lifecycle debugging)
- DEPRECATED markers on legacy CompleteRequest/CompleteResponse models
