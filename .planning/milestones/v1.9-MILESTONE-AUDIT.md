- **Nature:** Infrastructure gap — `TokenPayload.role`, `RequireAdmin`, `ADMIN_ROLE` all exist, but the login endpoint doesn't fetch roles from Frappe
- **Impact:** Admin endpoints work only with manually-created tokens (test scripts). Production admin login would need role lookup added to auth.py
- **Blocking:** No — Phase 28 scope was infrastructure only
- **Future fix:** Add Frappe role fetch in auth.py login, pass `role=` to `create_access_token`
