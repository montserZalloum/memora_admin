### Plan-Centric JSON Structure

**Final folder structure:**
```
public/files/cdn/
├── lessons/                              # SHARED - lesson content (stages)
│   └── {lesson_id}.json
│
└── plans/
    └── {plan_id}/
        ├── manifest.json                 # Plan metadata + subject list
        └── subjects/
            └── {subject_id}/
                ├── _h.json               # Hierarchy (with Plan Overrides applied)
                └── units/
                    └── {unit_id}_c.json  # Unit content (topics + lessons metadata)

private/memora_bitmaps/
└── {subject_id}_b.json                   # Bitmap metadata (shared, per-subject)
```

**Key Design Decisions:**

| Decision | Rationale |
|----------|-----------|
| Lessons shared at root | Content doesn't change per plan, only visibility |
| Subjects nested in plans | Same subject can have different visibility per plan (via Plan Overrider) |
| Bitmap files per-subject | Progress tracking is subject-based, not plan-based |
| No deprecated files | Clean slate - no real data exists yet |

### `is_free_preview` Derivation Logic

```python
def calculate_is_free_preview(subject_id: str, plan_id: str) -> bool:
    """
    Returns True if ANY unit OR topic in the subject has is_free=True
    (after Plan Overrides are applied).
    """
    # Get units for subject (filtered by Plan Overrides)
    for unit in get_visible_units(subject_id, plan_id):
        if unit.is_free:
            return True
        for topic in get_visible_topics(unit.name, plan_id):
            if topic.is_free:
                return True
    return False
```

### Build Trigger Flow

```
Plan saved/updated
    │
    ▼
Hook: on_plan_updated()
    │
    ▼
Redis: SADD memora:build:pending:plan:{plan_id}
    │
    ▼ (2-min debounce)
    │
Build Worker picks up
    │
    ▼
generate_plan_json(plan_id)
    │
    ├── Generate manifest.json
    │
    ├── For each subject in plan:
    │   ├── Apply Plan Overrides
    │   ├── Generate _h.json (hierarchy)
    │   ├── Generate unit_*_c.json files
    │   └── Calculate is_free_preview
    │
    └── For each lesson (if not exists):
        └── Generate lesson_{id}.json (shared)
```

**Additional triggers:**
- Subject in plan updated → queue plan build
- Plan Subject added/removed → queue plan build
- Plan Overrider created/updated → queue plan build
