## Appendix: Redis Key Ownership Matrix

| Key Pattern | Writer | Readers | Janitors (Tasks) | TTL Policy |
|-------------|--------|---------|------------------|------------|
| `memora:devices:{user_id}` | DeviceService (Phase 8) | auth.py | device_sync.py (on admin removal) | None (persistent) |
| `memora:gamesession:{user_id}` | GameSessionService (Phase 9) | sessions.py, progress.py | session_cleanup.py (orphan removal) | 3600s (1 hour) |
| `memora:session:{user_id}` | SessionService (Phase 2) | auth.py (refresh endpoint) | None | 30 days (refresh token TTL) |
| `memora:wallet:{player_id}` | WalletService (Phase 5) | sessions.py, progress.py | streak_reset.py (reset streak field) | None (persistent) |
| `memora:progress:{user_id}:{subject_id}:v{ver}` | ProgressService (Phase 4) | progress.py, sessions.py | None | None (persistent) |
| `memora:lb:alltime` | LeaderboardService (Phase 10) | leaderboard.py | None | None (persistent) |
| `memora:lb:daily:{YYYY-MM-DD}` | LeaderboardService (Phase 10) | leaderboard.py | archive_daily_leaderboard (copy to archive) | None (archived then removed) |
| `memora:lb:weekly:{YYYY-Www}` | LeaderboardService (Phase 10) | leaderboard.py | archive_weekly_leaderboard (copy to archive) | None (archived then removed) |
| `memora:buffer:interactions` | sessions.py (Phase 9) | sync.py flush_interaction_buffer | flush_interaction_buffer (batch process) | None (list trimmed after processing) |
| `memora:dirty:progress` | ProgressService (Phase 4) | sync.py sync_dirty_progress | sync_dirty_progress (batch flush) | None (set cleared after sync) |
| `memora:dirty:wallets` | WalletService (Phase 5) | sync.py sync_dirty_wallets | sync_dirty_wallets (batch flush) | None (set cleared after sync) |

**Ownership rules:**
- Writers: Own the schema, set fields, manage lifecycle
- Readers: Read-only access, never modify
- Janitors: Cleanup, archival, or batch processing (modify after writer is done)
- TTL Policy: Auto-expiry if ephemeral, persistent if permanent
