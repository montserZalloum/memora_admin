### Critical Gap: Cache Invalidation

**Issue:** FastAPI pubsub listener does not handle `type: "plan"` cache invalidation messages

**Location:** `fastapi_app/core/pubsub.py` line 91

**Current behavior:**
```python
if msg_type == "hierarchy" and subject_id:
    # Only handles hierarchy invalidation
else:
    logger.debug("unknown_invalidation_message", ...)  # Plan messages fall here
```

**Missing:** Handler for `type: "plan"` messages with `plan_id` field

**Impact:**
- Plan manifest cache (1hr TTL) never invalidated after rebuild
- Mobile app receives stale plan data until cache expires
- Admin changes to Plans not immediately visible

**Fix required:**
1. Add Plan invalidation handler in `_handle_invalidation()` function
2. Register PlanService in app.state (similar to HierarchyService in main.py)
3. Call `plan_service.invalidate(plan_id)` on `type: "plan"` messages
