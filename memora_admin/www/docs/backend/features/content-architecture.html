ما هي؟

هرمية من 5 مستويات (مادة ← مسار ← وحدة ← توبيك ← درس) مع نظام خطط يجمع المواد لصف/تخصص/فصل، وخط أنابيب بناء تلقائي ينتج ملفات JSON.

من يستخدمها؟

المشرفون عبر Frappe Desk. أربعة أسطح تقرأ منها:

المراجعة اليومية ساحة التدريب مركز التحدي التحدي المباشر

الحالات الشائعة وحالات الحافة

الحالة السبب ما يجب التحقق منه
المادة لا تظهر is_published = 0 على المادة أو أحد مستوياتها تحقق من is_published على كل مستوى في السلسلة
لا أسئلة مراجعة is_reviewable = 0 أو لم يُعالج بعد تحقق من is_reviewable + حالة dirty set
البناء فشل خطأ في التوليد أو الرفع بعد 3 محاولات error_message في Build Queue
محتوى قديم في التطبيق الكاش لم يُبطل أو debounce نشط مفاتيح Redis أو انتظار 2 دقيقة
bit_index = 0 متكرر استيراد بيانات بدون bit_index أعد تعيين last_bit_index على المادة
خطة بدون مواد جميع المواد is_premium = 1 تحقق من is_premium في Plan Subject
Overrider لا يعمل ref_doctype أو ref_name غير صحيح تحقق من وجود العنصر وصحة action

استكشاف الأخطاء

البناء عالق في Processing

تحقق من Frappe scheduler وسجلات الأخطاء — قد يكون الـ worker معطّل

Review Items غير محدّثة

تحقق من sync_dirty_review_items في scheduler + حالة Redis dirty set

الهرمية ترجع null

المادة غير موجودة أو is_published = 0

الكاش قديم بعد التعديل

استدعاء queue_manual_build أو انتظار 2 دقيقة (debounce)

Plan Subject يتيم بعد حذف المادة

الـ cascade delete يجب أن يحذفها تلقائياً — تحقق من سجلات الأخطاء في build_trigger.py

إشعار بناء لم يصل

تحقق من اتصال Redis pubsub + build_complete realtime event

Bit Index (فهرس البت)

  • تلقائي عند إنشاء درس (before_insert)
  • تسلسلي لكل مادة (يبدأ من 0)
  • لا يُعاد استخدامه أبداً حتى لو حُذف الدرس
  • قفل SELECT FOR UPDATE لمنع التعارض
  • يُستخدم في FSRS لتتبع إتقان كل درس
