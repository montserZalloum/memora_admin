# Data Model: Session + Auth Service Tests

**Feature**: 011-session-auth-tests
**Date**: 2026-02-17

## Overview

This feature is a **test suite** — it creates no new entities. The data model documents the Redis structures and service interfaces being tested, which serve as the "schema" for test assertions.

## Redis Structures Under Test

### 1. Game Session Hash

**Key**: `{prefix}gamesession:{user_id}`
**Type**: Hash
**TTL**: 3600s (1 hour)

| Field | Type | Example | Notes |
|-------|------|---------|-------|
| `session_id` | string (UUID) | `"550e8400-..."` | Generated by `start_session` |
| `lesson_id` | string | `"LESSON-001"` | Lesson being played |
| `subject_id` | string | `"MATH-G5"` | Subject for hierarchy |
| `device_id` | string | `"device-abc"` | From X-Device-ID header |
| `started_at` | string (ISO 8601) | `"2026-02-17T12:00:00+00:00"` | UTC timestamp |

**Related global keys** (not prefixed):
- `memora:dirty:progress` — Set, dirty member format: `"{user_id}:{subject_id}:v{version}"`
- `memora:buffer:interactions` — List of JSON strings

### 2. Authentication Session

**Key**: `{prefix}session:{user_id}`
**Type**: String (JSON)
**TTL**: 30 days (2,592,000s)

```json
{"fid": "uuid-string", "plan": "PLAN-001"}
```

**Legacy format**: Plain string `"uuid-string"` (parsed as `{"fid": raw, "plan": null}`)

### 3. OTP Pending Registration

**Key**: `{prefix}pending:{pending_id}`
**Type**: String (JSON)
**TTL**: 300s (5 minutes)

```json
{
  "mobile": "201000000000",
  "password": "hashed_password",
  "display_name": "Test Player",
  "gender": "M",
  "grade": "Grade 10",
  "plan": "PLAN-001",
  "major": "Science",
  "otp": "1111",
  "attempts": 0
}
```

### 4. Phone Reservation Lock

**Key**: `{prefix}phone_reserved:{mobile}`
**Type**: String
**TTL**: 300s (5 minutes)
**Value**: `"1"` (SETNX atomic lock)

### 5. Password Reset State

**Key**: `{prefix}reset:{mobile}`
**Type**: String (JSON)
**TTL**: 300s (5 minutes)

```json
{"otp": "1111", "attempts": 0}
```

### 6. Single-Use Reset Token

**Key**: `{prefix}reset_token:{token}`
**Type**: String
**TTL**: 900s (15 minutes)
**Value**: Mobile number string (e.g., `"201000000000"`)

### 7. Rate Limit Counters

**Login rate limit keys** (via `RateLimiter`):
- `{prefix}ip:{ip_address}` — Integer counter, TTL=60s (set on first INCR)
- `{prefix}account:{account.lower()}` — Integer counter, TTL=60s

**OTP rate limit keys** (via `OTPService`):
- `{prefix}ratelimit:otp:phone:{mobile}` — Integer counter, TTL=600s
- `{prefix}ratelimit:otp:ip:{ip_address}` — Integer counter, TTL=600s

### 8. Resend Cooldown

**Key**: `{prefix}ratelimit:otp:cooldown:{mobile}`
**Type**: String
**TTL**: 60s
**Value**: `"1"` (flag)

### 9. Device Registry

**Key**: `{prefix}devices:{user_id}`
**Type**: Hash (no TTL — persists until removed)

**Fields per device** (6 fields):
| Field Pattern | Type | Example |
|---------------|------|---------|
| `device:{device_id}:name` | string | `"iPhone / iOS 17.0"` |
| `device:{device_id}:ua` | string | `"Mozilla/5.0 ..."` |
| `device:{device_id}:platform` | string | `"iOS"` / `"Android"` / `"Web"` |
| `device:{device_id}:last_login` | string (ISO 8601) | `"2026-02-17T12:00:00+00:00"` |
| `device:{device_id}:fingerprint` | string | `"iPhone:Apple:iOS:Mobile Safari"` |
| `device:{device_id}:push_token` | string | `""` (empty default) |

### 10. Progress Bitmap

**Key**: `{prefix}progress:{user_id}:{subject_id}:v{version}`
**Type**: Bitmap (string with SETBIT/GETBIT)
**Used by**: `SESSION_COMPLETE_SCRIPT` sets bits on lesson completion
